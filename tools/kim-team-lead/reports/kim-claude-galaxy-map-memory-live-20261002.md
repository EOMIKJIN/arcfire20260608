1. **react-native-svg(15.2.0) Android `SvgView`는 루트 `<Svg>` 하나당 뷰 크기 ARGB_8888 비트맵을 통째로 만든다** (`node_modules/react-native-svg/android/.../SvgView.java:253-269` `Bitmap.createBitmap(width,height)` → `canvas.drawBitmap`). 이 비트맵은 native heap(픽셀)과 HWUI GPU 텍스처 **양쪽**에 상주한다.
2. 지도 `<Svg>` 크기 = `mapContentSize` = 성계 좌표 span × 지도 뷰 크기 + 패딩 (`worldmap.tsx:1231-1238`), 상한 8192dp. 화면 크기가 아니라 **은하 전체 크기**다.
3. 실제 데이터(`GALAXY_SYSTEMS`)로 계산:
   - 레거시 가시 100성계 기준 span 2.70×3.32 → 1125×1571dp → **3165×4419px ≈ 53MB / 장**
   - (참고) 전체 757성계면 ≈ 132MB, 코어 21만이면 ≈ 4.6MB
4. 따라서 **지도 SVG 1장 ≈ 53MB가 native와 GPU에 각각** 잡힌다. HWUI 이미지 104MB(5장)는 이 비트맵 2세대(재렌더 시 구·신 텍스처 공존) + 소형 3장과 수치가 맞음 — **추정**(엔트리별 크기는 gfxinfo가 안 보여줌).
