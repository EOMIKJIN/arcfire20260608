# 강화 방향성 → 현재 시스템 설계안 (김플레이 · 2026-10-10 · 설계만, 미적용)

## 대표님 방향(10-10)
1. 강화는 새로 사는 비용보다 **싸게**.
2. 이미 투자한 재화가 아깝지 않게 — 기존 장비 가치를 유지하며 다음 단계로 갈 수 있는 경제적 선택지.
3. 최적 옵션을 가진 3레벨 장비를 강화하는 편이 세팅(민첩·치명 등)을 깨지 않고 스펙을 올리는 안전한 길.
4. 강화 완료 = **다음 단계 기본형의 85~90%** (구매가와 비슷하게 맞추거나, 성능을 조금 낮추고 재화 소모를 줄임).
5. 강화품은 특정 세팅에 특화되는 추가 스탯·효과·기능(가능하면 설계).

## 0. 현재 상태 (측정)
사다리 함선 기본 전투력(강화 0 · 같은 L30 · 트윈 지표) — **단계가 올라도 거의 그대로**:
| 단계 | 함선 | HP/실드 | 직전 대비 | 가격 |
|---|---|---|---|---|
| 0 | 지급(파이터 Mk.I) | 560/210 | — | 0 |
| 1 | 구축함 | 600/250 | ×1.02 | 89만 |
| 1.5 | 구축함 개량 | 580/220 | ×0.93 | 126만 |
| 2 | 순양함 | 600/235 | ×0.97 | 269만 |
| 2.5 | 순양함 개량 | 610/240 | ×1.20 | 445만 |
| 3 | 순양전함 | 620/245 | ×0.85 | 1,069만 |
| 3.5 | 순양전함 최종 | 640/255 | ×1.04 | 1,588만 |
| 4 | 드레드노트 | 680/265 | ×0.85 | 3,390만 |
- 광물 강화는 고정치(+50 HP · 피해 +1)라 초반 함선에서 풀강 ×7.6(직전 보고). 장비·무기는 강화 시스템 자체가 없음(등급을 새로 사는 것뿐).

## 1. 설계 원칙 — 「구매 사다리 × 강화 다리」 한 쌍
```
기본형 B(n) ──강화──▶ 0.875 × B(n+1) ──구매──▶ B(n+1) ──강화──▶ 0.875 × B(n+2) …
            (비용 ≈ 다음 가격의 50~60%)      (+14% 체감)
```
- 다음 단계 기본형 대비 강화 완료 비율 `upgrade_cap_ratio_of_next` = **0.875**(85~90% 중앙 · CSV).
- 강화 총비용 = 다음 단계 구매가 × `upgrade_cost_ratio_of_next_price` = **0.55**(CSV) → 성능 87.5%를 55% 비용에(방향 1·4 「성능 약간 낮추고 재화 소모 줄임」).
- 강화는 지금 가진 것을 키우는 것 → 투자가 버려지지 않음(방향 2). 다음 것을 사도 된다/안 사도 된다는 **선택지**가 생김.

## 2. 함선
### 2-1 함선 기본 곡선(전제 · PB-G5 대체)
- 본 등급 한 단계 = 기본 전투력 ×`hull_step_power_ratio`(제안 **1.6**). 시작→드레드노트(4단) ≈ ×6.6 전투력(능력치당 약 2.6배). 숙련(L60 ×1.6)·장비·스킬·강화가 위에 더해짐.
- 강화 완료 = 0.875 × 1.6 = **자기 기본형의 ×1.4**.
- **반 단계(_upgraded Mk.II) 정리 권고**: 「Mk.I 강화 → 다음 등급 87.5%」가 반 단계 역할을 그대로 함. 반 단계 구매는 강화와 겹쳐 선택이 헷갈림 → 구매 사다리에서 빼고(행 유지) 4단 구매 + 강화로 단순화. (대표님 결정)
### 2-2 함선 강화(광물 강화 개편)
- 효과를 **함선 기준 %**로(HP·실드·무기 피해·연사·선회). 레벨당 %는 「강화 완료 = 자기 기본형 ×1.4」가 되게 도구가 계산해 CSV에 씀(레벨 상한 정책 그대로 사용).
- 비용: 강화 총비용 = 다음 등급 가격 × 0.55를 레벨별로 나눔(뒤로 갈수록 비싸게). 재료 = 그 등급 구간 광물(광물 사다리 ferrite→…→voidstone)로 환산 + 크레딧 일부(광물만으로는 후반 금액을 못 채움).
- 함선별 저장·넘기지 않음(10-10 결정) 유지.
- **투자 보존 선택지(방향 2) — 대표님 결정**: 강화한 함선을 팔거나 격납고에 둘 때 가치 반영. 예: 판매가 = 함선가 + 강화 투자 × 40%. (강화를 다른 함선으로 넘기지는 않음)
### 2-3 함선 특화(방향 5)
강화 5강·10강에서 특화 하나 선택(되돌리기는 비용) — 기존 효과 통로만 사용(코드 효과 추가 없음):
| 특화 | 5강 | 10강 |
|---|---|---|
| 화력형 | 무기 피해 +% | 재장전 −% |
| 방어형 | 실드 +% | 받는 피해 −% |
| 기동형 | 회피(AC) + | 이동·선회 +% |

## 3. 장비·무기 강화(신규 · 방향 3)
- 장비 한 개(인벤토리 칸 단위)를 **+1~+5** 강화. +5 = 다음 등급 같은 계열 효과의 87.5%. 총비용 = 다음 등급 가격 × 0.55(광물 + 크레딧).
- 아이템을 그대로 쓰므로 세팅(어느 칸에 어떤 계열)을 깨지 않음. 내구도는 그대로 이어짐.
- 특화 옵션(방향 5): +3·+5에서 계열별 옵션 중 하나 선택 — 표 `equipment_upgrade_perks.csv`(계열·단계·옵션id·효과 키·값). 효과 키는 기존 장비 효과 키(회피·재장전·ECM·탐지·피해감소 등)만 써서 코드 효과 추가 없이 가능.
- 무기 강화: 같은 구조(피해·재장전). **치명 옵션은 고지**: 지금 치명은 스킬 바인드에서만 처리 → 무기 단위 치명 옵션은 전투 코드에 효과 통로를 새로 만들어야 함(코드 필수 · 2단계).
- 저장: 인벤토리 칸(`CargoItem`)에 `upgradeLevel`·`perkIds` 추가, 장착 칸은 이미 칸 번호를 기억(`sourceInventoryIndex`)하므로 장착 효과 집계가 칸 값을 읽게 확장.
- 전제(앞선 결정 대기): 장비 1~3등급 가격이 기준축보다 매우 싸서 「다음 등급 가격 × 0.55」가 의미 없게 작음 → 1~3등급 가격 정리가 먼저.

## 4. 적용 순서(제안)
| 단계 | 내용 | 값 변경 |
|---|---|---|
| U1 | 정책 CSV(`upgrade_cap_ratio_of_next` 0.875 · `upgrade_cost_ratio_of_next_price` 0.55 · `hull_step_power_ratio` 1.6) + 도구가 함선 기본 곡선·강화 % ·비용을 계산해 CSV 생성 | 있음(함선 스탯·광물 강화) |
| U2 | 광물 강화 % 효과로 전환(전투 계산은 같은 경로) · 특화 선택(함선) | 있음 |
| U3 | 장비 1~3등급 가격 기준축 정렬 → 장비 강화 +1~+5 · 특화 옵션 | 있음 |
| U4 | 무기 강화 · 치명 옵션(전투 코드 통로 신설) | 있음 · 코드 필수 |
| 공통 | 플레이봇: 강화/구매 선택을 「전투력 상승 ÷ 비용」으로 고르게(사람과 같은 선택지) → 벤치로 절벽·정체 확인 → 실기 | — |

## 5. 대표님 결정 필요
1. 비율: 강화 완료 = 다음 기본형의 **87.5%**, 강화 총비용 = 다음 가격의 **55%** — 이대로?
2. 함선 기본 곡선: 본 등급 한 단계 **×1.6**?
3. 반 단계(Mk.II) 함선을 구매 사다리에서 빼고 「4단 구매 + 강화」로 단순화?
4. 투자 보존: 강화한 함선 판매가에 강화 투자 40% 반영?
5. 장비 1~3등급 가격 기준축 정렬(장비 강화의 전제)?
6. 순서: U1·U2(함선) 먼저 → U3(장비) → U4(무기·치명)?
