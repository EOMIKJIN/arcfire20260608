# 플레이봇 고도화 — 인간 플레이 안전 규칙 · 「도전 대상」 (김플레이 · 2026-10-10)

대표님 지시
- 「전함은 파괴당하라고 있는 게 아니라 돈을 벌어 강화하려고 있다. 파괴되면 우회하고 안전한 전투로 돌아가라. 50:50이면 도전, 5~10회 파괴는 OK, 같은 전투·세팅·행동 20회 넘는 파괴는 무조건 막아라.」
- 「상식적으로 수백·수천 번 파괴당하는 일을 반복하는 경우가 어딨냐.」
- 「항상 다음 도전 대상이 있고, 막히면 여러 대안 행동을 하다가 충족되면 도전해야 한다(정체·완전한 벽 방지).」

## 2. 원인 → 반영 (트윈 행동 규칙)
| # | 발견(근거) | 반영 |
|---|---|---|
| 1 | 파괴의 거의 전부가 **목적 이동(퀘스트·편입) 중 이동중 조우** — 목적 이동은 위험 상한이 없었다 | 목적 이동 상한 0.1 · 넘으면 **도전**(위험 ≤ 25% · 파괴 뒤 쉬는 중 아님 · 같은 성계 매복 2회 미만) |
| 2 | 막다른 성계(synth_066 — 출구 blood_field 위험 0.9)에 갇혀 수색만 반복(seed2 D191~ 정체 85회) | **도전 대상 막힘이 길어지면 단계적 감수**: 정체 1일 → 50% · 3일 → 마지막 도전(어떤 출구든). 단 같은 성계·같은 세팅 매복 **20회는 무조건 차단** |
| 3 | 매복 기억이 「같은 레벨」 동안 유지 → 최고 수련장을 레벨 오를 때까지 못 감(교착) | 매복 기억 = 같은 레벨 **3일** |
| 4 | 자금 벌이 중 퀘스트를 해도 행동이 'trade'로 남아 떠돌기 상한(0.03)에 막힘 → 두 목적지 왕복으로 연료만 소진 | 퀘스트 이동은 항상 목적 이동 |
| 5 | 한 홉 값만 들고 성장 이동 → 중간 성계에서 빈털터리 | 성장 이동은 **항로 전체 연료**가 있을 때만 |
| 6 | 막힌 퀘스트가 진행 칸을 계속 차지 → 본편 정체 | 퀘스트 이동이 막히면 **하루 보류**하고 다른 퀘스트(본편 먼저)로 → 다시 도전 |
| 7 | 해적 격파 목표 전장이 「마지막 퀘스트 행성」(core_prime tcl56)으로 판정 → 보류 퀘스트 영구 미복귀 | **이 퀘스트의 직전 목표 행성 → 의뢰 행성(전투 가능 시) → 마지막 퀘스트 행성** |
| 8 | 위험 홉 필터로 교역로가 거의 사라져 돈 엔진 붕괴(평생 수입 33만 · 함선 89만 못 삼) | 교역로는 **기대값**(순익 − 함선·**실은 화물** 기대 손실)으로 고르고 홉 위험 ≤ 0.2만 |
| 9 | 함선 시장·조선소·격납고 보충 이동이 떠돌기 상한에 막혀 돈이 있어도 함선을 못 삼(seed4 114만) | 구매·보충 이동 = 목적 이동 |
| 10 | 산 함선으로 0.97 수련을 수천 번 → 3%씩 잃어 함선 상실 47/시드 | **산 함선이면** 평소 전투 0.995 · 이동 0.02 · 도전 홉 0.1 |
| 11 | 안전 대안이 그 자리 수색만 → 성장 없음 | 대안 = 기대 경험치 큰 안전 수련장 → 가까운 안전 전장 → 여기서 수련 → 채굴·매도 |

「도전 대상」 흐름 = 퀘스트·정복·함선 구매·보충(목적) → 막히면 보류 + 성장 대안(수련·채굴·교역·강화) → 승률 50:50 또는 막힘 지속 시 도전 → 같은 세팅 20회 상한.
