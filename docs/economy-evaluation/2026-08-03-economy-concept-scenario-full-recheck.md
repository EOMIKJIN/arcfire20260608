2. mid/late 잔여 gap → CPH 또는 **무기 가격 곡선 약한 보정** (일괄 할인 금지)  
3. `npm run sim:economy` → deltaId 갱신 · balance-ops 재실행  
4. **완료 기준**: band critical=0 또는 late warn만 + whaleF2p ok  

### Phase B — 월드 물류·바닥 허브 (Wave2) — **즉시 병행 가능**

1. `core_prime` convoy 1원인 수정  
2. shadow_market (및 선택 eden deficit) 수요/루트 **최소 패치**  
3. `audit:planet-economy-3h` core_prime fail=0  

### Phase C — 배치 원자성 (Wave3) — **단기**

1. started ≠ complete  
2. 미완료 시 당일 재시도  
3. 일 1회 멱등 유지  

### Phase D — **플레이어 CR·시나리오·매트릭스 정렬** — **제품 P0 (신규 READY 필수)**

> A만 끝내면 “감사 통과”로 오해할 수 있음. **컨셉 루프 복구는 D가 본체**.
