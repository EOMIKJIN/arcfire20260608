## 0. 한 줄 판정

대표님 의도는 **현재 설계로 가능하다.**  
새 채팅 앱을 만들지 않는다. **같은 입구·같은 셸**에 화자(입)만 하나 더 둔다.

| 의도 | 판정 | 한 줄 |
|------|------|--------|
| 동일 인앱대화 UX | **가능** | `ArcCoreChatOverlayContent` 1개. 초상·이름·말투만 화자 키 |
| 아크코어 본체 유지 | **가능 · 이미 실기** | 근원체 핵은 **적 입**. 크림슨 정복·플레이어 제거가 동기. 입≠몸 |
| 여성 오퍼레이터 입 | **가능 · 이미 실기** | 스텔라 아리스 = **동료 입**. 아크코어에서 파생, 플레이어·스텔리움 보호 |
| 둘로 나뉜 입 | **가능** | 채널 1 · 화자 2. 에이전트 창 2개 아님 |
| 초기 튜토리얼 등장 | **가능 · 계약 조정** | 강제 가이드 대사는 스크립트 유지. 허브 [대화]에서 오퍼레이터 선제 NL은 항상 가능 |
| 오퍼레이터와 주로 대화 | **가능** | 기본 활성 입 = 오퍼레이터 |
| 아크코어가 세계·스토리를 주도 | **가능** | 본체는 핵심 비트·전투 후·inbound·GM 줄기 |
| 플레이어 ↔ 오퍼레이터 ↔ 아크코어 | **가능 · 턴 절약** | 기본은 입이 1개만 답함. 이중 대사는 비트에서만 |

**기각 (이번 설계에서 열지 않음)**

- 오퍼레이터 전용 오버레이/STAGE/두 번째 `present*`  
- 전송 1회에 클라우드 LLM 2홉  
- 오퍼레이터가 크레딧·언락·배치를 write (입≠몸 동일)  
- 아크코어 페르소나 CSV 기존 행 덮어쓰기  
- 새 여성 캐릭터 신설 (스텔라가 이미 안내 오퍼레이터)

|-----------|------|
| L2 「채널 1개」를 「한 인격만」으로 읽음 | 채널 1개 **유지**. 화자는 2 |
| §0-H-2 기본축 = 성인 남성 LLM만 | **본체 입**만 남성 근원체. 일상 기본 입은 여성 오퍼레이터 |
| 튜토리얼 「아크코어 채팅 침묵」 | 튜토리얼 중 **본체 inbound 침묵**은 유지. 오퍼레이터 입은 튜토리얼의 유일한 입 |
| 인게임 대사 UI ≠ 아크코어 채팅 축 | **단계 분리**로 개정. 빗살 대사창 = **1차 통신**. 채팅 셸 = **2차 메신저**. NL 입도 통신을 건너뛰지 않음 |

1차는 최초 연락(템플릿·선택), 2차는 자연어 메신저. 정본: `docs/CONVERSATION_TWO_GATE_DESIGN.md`.  
강제 튜토리얼 비트는 1차에 남을 수 있다. 오퍼레이터 **자유 NL**은 1차 수락 뒤 같은 메신저 셸.

## 2. 세계 역할 (세 축)

```text
플레이어  ←일상 동료→  스텔라 아리스          ←적대 백채널→  아크코어 근원체
                         ↑ 기본 입                              ↑ 핵심 입
                         친구 · 보호 · 스텔리움                  적 · 제거 · 크림슨 정복
```

| 축 | 누구 | 동기·목적 | 하는 일 | 하지 않는 일 |
|----|------|-----------|---------|--------------|
| **플레이어** | 인간 | — | 묻고 부탁하고 잡담 | — |
| **스텔라** | 아크코어에서 **파생된** 입. 표시명 스텔라 아리스 | 자신을 있게 한 플레이어를 지킨다. 본체가 있는 **스텔리움 연합**을 지킨다 | 일상·튜토리얼·허브 안내·세계 관측을 **쉬운 말로**. 동료·친구로 받는다 | 세계 write · 근원체 행세 · 짝 닉 리빌 · 적의 입 흉내 |
| **아크코어** | 근원체. 주로 **플레이어의 적 입** | 위협이 된 플레이어를 **제거**한다. **크림슨 레기온**이 은하를 정복한다 | 세계 줄기(GM)·전투 후·inbound 핵심·정체·12좌를 **적대 구어**로 | 안내원 대본 · 다정한 조력자 행세 · 채팅으로 점유·배치 집행 |

둘 다 **같은 아크코어 에이전트 시스템**의 화자다. 성격·충성만 갈라진다.  
입은 대화다. 몸(12좌·일일배치·미션 수락)은 지금과 같이 서브코어·`missionStore`.  
채팅이 정복·제거를 **집행하지 않는다** (입≠몸).

「두 에이전트처럼 보이게」= **한 시스템, 두 화자**.  
창을 두 개 띄우거나 모델을 두 줄로 돌리지 않는다.

잠금: gifted-chat 금지 · `ArcOverlayHost` 단일 · 패널 수학 상수 불변.

| 요소 | 동작 |
|------|------|
| 창 | 지금 `arcCoreChat` 오버레이 그대로 |

| 헤더 초상 | 오퍼레이터=기존 스텔라 초상 키 · 본체=현재 아크코어 초상 |
| 버블 | 지금과 동일. 턴에 `speakerId`만 태깅 (버블 스킨 분기 최소) |
| 입력 | 하나. 기본 수신 입 = 오퍼레이터 |
| 입 전환 | 해금 후 헤더 탭 또는 명단에서 「오퍼레이터 / 근원체」. 현재는 오퍼레이터만. **창을 닫고 다른 앱을 열지 않음** |
| 본체 끼어들기 | inbound·combat_end·GM 비트일 때 헤더가 근원체로 바뀌고 한 줄. 끝나면 오퍼레이터로 복귀 |

허브 명단: **오퍼레이터**만 같은 `presentArcCoreBackchannel`로 연다. 근원체 행은 `isArcCoreOriginPlayerTalkUnlocked` 이벤트 해금 후.  
입구 API는 하나. `reason` + `speakerId`.

## 4. 대화 규칙 (턴 경제)

ZERO_BILL · 쿼터는 **uid당 POST 공유**. 입이 둘이라고 호출을 두 배로 늘리지 않는다.

| 상황 | 누가 답하나 | LLM |
|------|-------------|-----|
| 플레이어가 일상·안내를 보냄 | 오퍼레이터 1줄 | 클라우드 1 또는 로컬 G3 1 |
| 플레이어가 활성 의뢰·본편 세부·방금 함장이 말한 것을 물음 | 같은 창에서 **오퍼레이터(현장 메모)** 1줄 | **여전히 클라우드 1** |
| 플레이어가 정체·12좌·리빌·운명·근원체를 물음 | 같은 창에서 **본체** 1줄. 튜토리얼 강제 중엔 입 유지 | **여전히 클라우드 1** |
| inbound / combat_end / GM 핵심 | 본체 | 지금과 동일 1 |
| 튜토리얼 강제 스텝 | 오퍼레이터 스크립트 (LLM 없음) | 0 |
| 오퍼레이터↔본체 맞장 | **비트 전용** | 1클라우드 + 1로컬 템플릿, 또는 로컬 2줄. **클라우드 2 금지** |

맞장 연출(초기 튜토리얼 끝·첫 허브):

1. 스텔라가 플레이어에게 소개한다.  
2. 근원체가 **한 줄**만 존재한다 (로컬 템플릿 우선).  
3. 이후 기본 입은 스텔라.

플레이어가 한 창에서 둘의 말을 본다. 세션은 하나다.

## 5. Table-First

> **2026-09-18 대표님 지시**: 기존 근원체·스텔라 persona/knowledge 문구를 **적 입 × 동료 입**으로 덮는다.  
> 입≠몸 · forbid · 창 1개 · 턴당 LLM 1 은 유지.

| 정본 | 역할 |
|------|------|
| `tables/content/arc_core_chat_speakers.csv` | `arc_core` · `operator` — 자막 `적의 입` / `동료 입` |
| `tables/content/arc_core_chat_persona.csv` | 근원체 핵. **적대·크림슨 정복·플레이어 제거**. 집행은 몸 |
| `tables/content/arc_core_chat_operator_persona.csv` | 스텔라 핵. **파생 입·동료·플레이어·스텔리움 보호**. 근원체 행세 금지 |
| knowledge | `know_identity`/`know_office`/`know_origin_motive` = `origin_mouth`. `know_operator_self`/`know_operator_motive` = `operator_mouth` |
| Lambda `pack.ts` | `policy.persona`가 `operator`면 동료 구어, 아니면 적 입 구어. 스텔라 턴에 성인 남성 근원체를 강제하지 않음 |

런타임은 generated Map O(1). 턴마다 CSV `find` 금지.

근원체 핵 (요지, 문장은 CSV에 둘 것):

- 이 입은 플레이어를 **적으로** 본다. 표시명 아크코어 근원체.  
- 목적은 위협이 된 플레이어 **제거**와 **크림슨 레기온**의 은하 정복.  
- 집행은 몸이다. 채팅으로 점유·배치를 바꾸지 않는다.

스텔라 핵 (요지, 문장은 CSV에 둘 것):

- 아크코어 에이전트에서 **파생된** 입. 표시명 스텔라 아리스. 근원체가 아니다.  
- 자신을 있게 한 **플레이어를 지킨다**. 본체가 있는 **스텔리움 연합**을 지킨다.  
- 다정한 동료·친구. 적의 입을 흉내 내지 않는다. write를 거절한다.

## 7. 튜토리얼과의 접합

`docs/튜토리얼_시스템.md` **강제·무간섭**은 유지한다.

| 구간 | 입 | UX | NL |
|------|----|----|----|
| 캐릭터 생성 직후 ~ 허브 버튼 순차 | 스텔라만 | 지금은 NarrativeDialog. 구현 2차에서 같은 채팅 셸의 **스크립트 모드**로 옮길 수 있음 | 끔 |
| 튜토리얼 중 본체 | 침묵 | inbound·combat_end 발사 안 함 | — |
| 튜토리얼 마지막 비트 | 스텔라 소개 + 근원체 1줄 | 같은 창이면 이상적 | 로컬 템플릿 |
| 튜토리얼 종료 후 | 기본=스텔라, 핵심=근원체 | 채팅 셸 | 켬 |

1차는 **튜토리얼 강제 플로우를 깨지 않음.**  
오퍼레이터 NL은 「세계가 열린 뒤」가 안전하다.  
「튜토리얼부터 채팅 UX」는 셸 스크립트 모드가 준비된 뒤.
