## 새 문서 두는 법

1. 위 폴더 중 하나에 넣고 그 폴더 README 표에 한 줄 추가한다.
2. 맞는 폴더가 없으면 폴더를 새로 만들고 README와 이 표에 한 줄씩 추가한다.
3. 최상위(`docs/`)에 바로 두지 않는다.
