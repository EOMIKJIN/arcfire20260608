# 레벨 밸런싱 중심 추가 작업 리스트

작성일: 2026-05-09

## 목적

아크파이어 온라인은 이브 온라인·스텔라리스 계열의 우주 전략 MMORPG 방향을 갖는다. 현재는 테이블 정본과 아크코어 기반 작업이 일부 구축되어 있으나, 경제·전투·아이템·스킬·미션이 하나의 레벨 밸런스 곡선으로 묶여 있지 않다.

이 문서는 현재 코드/테이블 기준으로 확인된 미구현 영역을 정리하고, 이후 작업을 레벨 밸런싱 중심으로 정렬하기 위한 실행 목록이다.

## 현재 확인된 상태

- 플레이어 레벨 테이블은 `tables/content/player_level_exp.csv`에 1~60레벨 구간으로 존재한다.
- 스킬 테이블은 `tables/content/skills.csv`에 전투·항해·무역·함대 카테고리와 `levelRequired`, 선행 스킬, 효과 필드가 있다.
- 미션 테이블은 `tables/content/missions.csv`, `mission_objectives.csv`, `mission_reward_items.csv`로 분리되어 있고, 현재 3개 초반 미션만 정의되어 있다.
- 무기 테이블은 `tables/content/weapon_list.csv`에 1~60레벨 요구치와 가격·피해·쿨다운·사거리 정보가 있다.
- NPC 함장/전함은 `npc_ai_captains.csv`, `npc_ai_ships.csv`에 레벨·경험치 곡선·전투 스탯이 있으나, 플레이어 성장 곡선과 직접 연결된 밸런스 검증은 없다.
- 경제는 무역품 가격/재고/수요 스토어와 일일 가격 서브코어가 있으나, 플레이어 레벨·지역 위험도·미션 보상·전투 보상과 통합된 수익 곡선은 없다.
- 아크코어는 수송선단 이동과 행성 궤도 함장 배치 스냅샷 기반을 갖기 시작했으나, 레벨 권역별 경제·전투·미션 배치를 최종 조정하는 밸런스 정책은 아직 없다.

## 핵심 미구현 격차

### 1. 성장 곡선 단일 기준 부재

현재 플레이어 레벨, 무기 요구 레벨, NPC 전함 스탯, 성계 `enemyLevel`, 미션 보상 경험치가 각각 존재하지만 한 곡선으로 검증되지 않는다.

필요 작업:

- `player_level_exp.csv` 기준으로 레벨 구간을 1~10, 11~20, 21~40, 41~60 등으로 나누고 각 구간의 목표 전투력·수익·장비 가격 범위를 정의한다.
- `systems.csv`의 `enemyLevel`, `weapon_list.csv`의 `requiredLevel`, `npc_ai_ships.csv`의 전투 스탯이 같은 티어에 들어오는지 검사하는 밸런스 감사 스크립트를 만든다.
- 레벨업 예상 시간 기준을 정한다. 예: 초반 1레벨 10~20분, 중반 1레벨 1~2시간, 후반 장기 성장.

### 2. 미션 보상과 레벨업 곡선 미연동

현재 미션은 3개만 있고 보상 경험치가 `player_level_exp.csv`와 맞물려 설계되어 있지 않다. 미션 보상 아이템 테이블도 비어 있다.

필요 작업:

- 레벨 1~10 튜토리얼/초반 미션 체인을 최소 10~15개로 확장한다.
- 각 미션에 기대 소요 시간, 위험도, 권장 레벨, 권장 함선/무기 티어를 추가하는 컬럼 확장을 검토한다.
- 미션 보상 경험치가 다음 레벨 필요 경험치의 몇 퍼센트인지 규칙화한다.
- `mission_reward_items.csv`를 실제 보상 아이템 지급 경로와 연결한다.
- 미션 완료 시 스킬 포인트, 장비, 경제 평판, 행성 영향도 중 무엇을 지급할지 보상 타입을 분리한다.

### 3. 스킬 효과의 실제 전투/경제/항해 적용 부족

스킬 테이블에는 효과가 있으나, 실제 전투·무역·항해 계산에 일관되게 적용되는 구조가 부족하다.

필요 작업:

- `effectType`, `effectStat`, `effectValue`를 해석하는 공통 스킬 효과 해석기를 만든다.
- 전투 스킬은 명중, 피해, 크리티컬, 실드, 쿨다운에 연결한다.
- 무역 스킬은 시세 확인 범위, 매입/판매 보정, 밀수 위험, 세금/수수료에 연결한다.
- 항해 스킬은 이동 속도, 위험 회피, 스캔 효율, 점프 비용에 연결한다.
- 함대 스킬은 아크코어/NPC 동행/윙맨/함대 버프에 연결한다.
- 액티브 스킬은 쿨다운·사용 조건·전투 UI 입력 경로를 만든다.

### 4. 무기 레벨과 실전 전투력 검증 부재

`weapon_list.csv`에는 1~60레벨 무기가 있으나 피해값, 쿨다운, 가격이 실제 플레이어 레벨·NPC 체력·경제 수익과 연결 검증되지 않았다. 일부 값은 극단적으로 커서 운영 밸런스 기준이 필요하다.

필요 작업:

- 무기별 DPS, 사거리, 쿨다운, 가격, 요구 레벨을 계산하는 감사 리포트를 만든다.
- 같은 레벨대 무기를 근거리/장거리/광역/드론/함재기 역할로 나누고 역할별 기대 DPS 범위를 정한다.
- `weapon_list.csv`의 `damageDiceText`, `critOrRangeText`, `featureImplementId`, `functionKindId`를 실제 전투 기능과 연결한다.
- 전투 렌더/판정 체인은 `weapon_list.csv -> missileWeaponId/laserWeaponId -> 런타임/이펙트 모듈` 단일 체인을 유지한다.
- 상위 무기 가격이 경제 수익 곡선으로 도달 가능한지 검증한다.

### 5. 경제 수익 곡선과 레벨 곡선 미연동

무역 엔진과 아크경제 스토어는 있으나, 레벨별 기대 크레딧 수입·장비 구매력·위험 보상 배율이 명확하지 않다.

필요 작업:

- 레벨 구간별 목표 시간당 수익을 정의한다.
- 안전/중립/PvP/엔드게임 권역별 기대 수익과 손실 위험도를 정의한다.
- 무역품 `baseBuyPrice`, `baseSellPrice`, `baseProfit`, 재고, 수요 변화를 레벨 구간과 연결한다.
- 수송선단 거래가 가격 modifier에 주는 영향의 상한/하한을 정한다.
- 행성 소유권, 클랜 해산 명령서, 전함 판매 1cr 테스트 가격 등 임시 가격을 운영 가격으로 교체한다.
- 채굴 수익, 잔해 수색 보상, 무역 수익, 전투 보상을 같은 크레딧/시간 기준으로 비교하는 밸런스 시트를 만든다.

### 6. NPC/성계 난이도와 보상 연결 부족

성계에는 `enemyLevel`이 있고 NPC 전함에는 전투 스탯과 `expReward`가 있으나, 플레이어 레벨과 보상/위험도가 통합되어 있지 않다.

필요 작업:

- `systems.csv.enemyLevel`을 권장 플레이어 레벨 범위로 해석하는 정책을 만든다.
- NPC 전함 `maxHp`, `maxShield`, `armor`, `attackBonus`, `damageDice`, `expReward`를 성계 레벨별 공식으로 감사한다.
- 전투 승리 보상 경험치와 크레딧을 미션/무역 수익과 비교한다.
- PvP/엔드게임 권역은 손실 위험과 보상 배율을 별도 정의한다.
- 아크코어 행성 궤도 함장 배치 스냅샷이 향후 레벨/위험도 기반으로 함장 이동을 결정할 수 있게 정책 입력값을 정의한다.

### 7. 아이템 레벨/장착 제한 체계 부족

아이템 정의에는 가격·카테고리·태그가 있으나, 장착 가능 레벨, 스킬 요구치, 함선 슬롯 요구치, 권역 제한이 일반화되어 있지 않다.

필요 작업:

- 모든 장착형 아이템에 `requiredLevel`, `requiredSkillIds`, `slotType`, `powerCost`, `mass`, `tier` 같은 공통 속성을 도입할지 결정한다.
- 무기 모듈과 전함 인도 아이템을 일반 무역품과 분리해 가격/장착/판매 정책을 따로 둔다.
- `mining_drone_mk1`처럼 `effectPending=true`인 아이템의 실제 효과 연결 작업을 목록화한다.
- 인벤토리/격납고/장착 슬롯에서 아이템 레벨 제한을 검사한다.

## 우선 작업 순서

1. 레벨 밸런스 기준표 작성

- 레벨 구간별 목표 전투력, 시간당 수익, 장비 가격, 미션 경험치 비율을 정의한다.
- 산출물: `tables/balance/level_band_targets.csv` 또는 유사 테이블.

2. 밸런스 감사 스크립트 작성

- 플레이어 레벨, 성계 레벨, 무기 요구 레벨, NPC 전투력, 미션 보상, 무역 수익을 한 번에 검사한다.
- 산출물: `npm run audit:balance`와 `tools/balance-audit/reports/latest.md`.

3. 초반 1~10레벨 미션 체인 확장

- 이동, 스캔, 채굴, 잔해 수색, 첫 전투, 첫 거래, 첫 스킬 학습을 모두 통과시키는 체인을 만든다.
- 산출물: 미션 CSV 확장 및 보상 아이템 연결.

4. 스킬 효과 해석기와 전투/무역 연결

- 패시브부터 먼저 연결하고 액티브 스킬은 이후 UI/쿨다운과 함께 연결한다.
- 산출물: `skillEffectResolver` 계층과 전투/무역 적용 지점.

5. 무기 실전 기능 연결

- `featureImplementId`, `functionKindId`별 구현 상태를 표준화한다.
- 미구현 기능은 명시적으로 `pending` 처리하고, 구현된 기능만 전투 판정에 반영한다.

6. 경제 수익곡선 정렬

- 레벨별 목표 수익과 실제 무역/채굴/전투/미션 보상을 비교해 가격표를 재조정한다.
- 테스트 가격 1cr 계열은 개발 플래그 또는 별도 테스트 테이블로 분리한다.

7. 아크코어 배치 정책 확장

- 현재 행성 궤도 함장 배치 스냅샷은 CSV 읽기 전용 기반이다.
- 이후 아크코어가 레벨 권역, 경제 상태, 이벤트, 클랜전, 위험도에 따라 함장 이동/교체를 적용한다.
- 목표는 “CSV는 함장 정본, 아크코어는 최종 배치 정책” 구조다.

## 완료 기준

- 한 레벨 구간에서 플레이어가 미션/전투/무역/채굴 중 어떤 루트를 선택해도 성장 속도가 극단적으로 벌어지지 않는다.
- 무기 요구 레벨과 가격이 해당 레벨대 경제 수익으로 설명된다.
- NPC 전투력과 성계 난이도가 플레이어 장비/스킬 성장 곡선과 대응된다.
- 스킬은 테이블에만 존재하지 않고 실제 전투/경제/항해 계산에 반영된다.
- 미션 보상은 레벨업, 장비 교체, 시스템 해금, 스킬 학습을 단계적으로 안내한다.
- 아크코어는 최종적으로 행성 궤도 함장 배치 스냅샷을 통해 함장 이동/교체를 관리한다.
