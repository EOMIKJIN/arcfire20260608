## 0. 핵심 개념

```
미개척 행성 → 플레이어 점유 → 시설 최초 건설(Lv0→1) → Lv2~10 업그레이드
    → 5대 스탯(R·P·D·T·E) 서서히 상승 → PGP·TDI 상승 → 행성 고유 경쟁력 형성
```

## 1. 행성 5대 스탯 기준값 및 시설 상승 메커니즘

### 1-1. 디폴트 50에서 시작하는 스탯 구조

행성의 5대 스탯(R·P·D·T·E)은 **초기값 50**으로 시작하며, 다음 감소 요인에 의해 지속적으로 하락 압력을 받는다.

| 감소 요인 | 대상 스탯 | 크기 |
|---------|---------|------|
| 드론 침공 성공 | D, T | 즉시 -5~-10 |
| 무점유 상태 지속 | 전체 | 일 -1 nudge |
| convoy 미운영 | R, P | 일 -2 nudge |
| 배치 미수행 행성 | E | 일 -1 |

### 1-2. 시설 레벨의 스탯 상승 기여 (일 1회 배치 반영)

> ⚠️ 모든 staN nudge는 **일 1회 배치(`runArcCoreDailyOpsBatch`)에서만 반영**. 즉시 갱신 금지.

| 시설 | 레벨별 일일 nudge | 대상 스탯 | 최대 누적(Lv10) |
|------|----------------|---------|--------------|
| 무역소 | +0.2/레벨 | R, P | **+2.0/일** |
| 조선소 | +0.1/레벨 | T | **+1.0/일** |
| 방위위성 | +0.3/레벨 | D | **+3.0/일** |
| 연구소 | +0.3/레벨 | T, E | **+3.0/일 (각각)** |
| 선술집 | +0.25/레벨 | P | **+2.5/일** |

### 1-3. 시설 전부 Lv10 달성 시 일일 스탯 상승량

| 스탯 | 기여 시설 | 일일 상승 | 월간 상승(30일) |
|------|---------|---------|--------------|
| **R(자원)** | 무역소 Lv10 | +2.0 | +60 (캡 적용) |
| **P(인구)** | 무역소+선술집 Lv10 | +4.5 | +135 (캡 적용) |
| **D(방어)** | 방위위성 Lv10 | +3.0 | +90 (캡 적용) |
| **T(기술)** | 조선소+연구소 Lv10 | +4.0 | +120 (캡 적용) |
| **E(환경)** | 연구소 Lv10 | +3.0 | +90 (캡 적용) |

> **캡**: 스탯 최대값 100. 시설 nudge + 전투/교역 nudge 합산이 100을 초과하지 않도록 클램핑.

### 1-4. PGP 연동

```
PGP = (R+P+D+T+E)/5 × 3,375 BMU

전 스탯 디폴트 50 → 84,375 BMU
시설 5종 모두 Lv10 + 3개월 운영 → 전 스탯 ~80 → 135,000 BMU (목표 상한)
```

### 5-3. 연구소 상세 기능

#### R&D 속도 단축
`_000_Arcfire_Planet_Final_Master_Plan.md`의 15단계 R&D 시간에 연구소 레벨 보너스를 곱적용한다.

```typescript
function getEffectiveRdTime(baseHours: number, laboratoryLevel: number): number {
  const rdSpeedBonus = LAB_RD_SPEED_BONUS[laboratoryLevel]; // 0.0 ~ 0.5
  return Math.floor(baseHours * (1 - rdSpeedBonus));
}
// 예시: 연구소 Lv10, 자원 15레벨 기본 104h → 실제 52h
```

#### 장비 분석 시스템 (신규)
연구소 레벨에 따라 특정 티어 무기·장비를 **분석(Analyze)**하여 성능 정보 열람 및 구매 우선권 획득 가능.

| 연구소 레벨 | 분석 가능 장비 티어 |
|-----------|-----------------|
| Lv1~2 | T1 무기·장비 기본 스탯 열람 |
| Lv3~4 | T2 무기·장비 기본 스탯 열람 |
| Lv5~6 | T3 무기·장비 기본 스탯 열람 |
| Lv7~8 | T4 무기·장비 기본 스탯 열람 |
| Lv9~10 | 특수 장비·엔드게임 장비 분석 |

#### 환경(E) 재생 기여
E스탯은 환경 피해나 배치 미수행 시 하락하는데, 연구소의 `E nudge`가 이 하락을 상쇄하고 점진적으로 상승시킨다.

```
E 변화량/일 = 연구소 nudge(+0.3~+3.0) - 환경 감소(-0.5~-2.0)
→ 연구소 Lv5 이상부터 E스탯 순 상승 전환
```

#### 바운티 보드 시스템

#### 용병 고용 시스템
선술집 레벨에 따라 고용 가능한 용병 등급이 확장된다.

| 용병 등급 | 해금 레벨 | 주요 효과 |
|---------|---------|---------|
| 일반 용병 | Lv1 | 단순 전투 보조 (전투 DPS +5%) |

| 특수 용병 | Lv7 | 전투 DPS +20% + convoy 호위 |
| 전설 용병 | Lv9 | 전투 DPS +30% + 전 스탯 보조 +1 |

#### 평판(Reputation) 시스템
선술집 레벨업 → 해당 행성의 팩션 평판 보너스 증가 → convoy 수수료 할인·거래 우대.

```typescript
interface TavernReputationEffect {
  factionRepBonus: number;      // % 보너스
  tradeDiscountPct: number;     // convoy 수수료 할인
  convoyAttractProbability: number; // convoy 자발 방문 확률
}
```

#### P스탯 상승 메커니즘
선술집은 행성 인구(P)와 가장 직접적으로 연결된다.

```
P 일일 nudge = 선술집레벨 × 0.25
바운티 완료 시 P+0.5 추가 nudge (일 1회 배치 집계)
convoy 방문 시 P+0.2 추가 nudge (일 1회 배치 집계)
```

## 7. 5대 스탯 × 시설 연동 종합 매트릭스

```
스탯 상승 경로 (일 1회 배치 기준):

R(자원) ── 무역소 레벨 × 0.2 /일
         ─ convoy 정산 nudge (기존)
         ─ 플레이어 매매 nudge (기존)

P(인구) ── 선술집 레벨 × 0.25 /일  ← 신규
         ─ 무역소 레벨 × 0.2 /일
         ─ convoy 유입·거래 횟수 nudge (기존)
         ─ 바운티 완료 +0.5 /일     ← 신규

D(방어) ── 방위위성 레벨 × 0.3 /일
         ─ 침공 격퇴 성공 +1 /회
         [감소] 드론 침공 성공 -5 즉시

T(기술) ── 연구소 레벨 × 0.3 /일   ← 신규
         ─ 조선소 레벨 × 0.1 /일
         [감소] 드론 침공 T 피해

E(환경) ── 연구소 레벨 × 0.3 /일   ← 신규
         ─ 환경 다양성 패스 (기존)
         [감소] 무점유 지속 -1 /일
```

## 12. 구현 주의사항 (v2.0)

1. **Table-First:** `facility_upgrade_levels.csv`에서만 로드. 코드 하드코딩 금지
2. **방위위성 DPS:** `defenseSatelliteCombatModifier` 외부 객체 — StarshipEngine PData 직접 수정 금지
3. **업그레이드 완료 판정:** `finishTimestamp` 기준만. 실시간 타이머 금지
4. **조선소 광물 캡:** `getFinalMineralUpgradeCap()` — `combatLevel`캡과 `shipyard`캡 중 낮은 값
5. **점유 상실:** 시설 레벨 유지, 데이터 삭제 금지. **nudge는 점유 중에만 발생**
6. **스탯 nudge 적용:** 일 1회 배치(`runArcCoreDailyOpsBatch`) 내 `runFacilityStatNudgePass` 신규 함수에서만 처리
7. **PlanetFacilityState:** `planetCoreRuntimeStore` AsyncStorage 정본
8. **조선소 건조 ≠ 구매:** `builtHullTierKeys` 갱신은 사전작업. 구매 조건은 `capital_hull_purchase_policy` 정본
9. **연구소 R&D 단축:** `getEffectiveRdTime(baseHours, laboratoryLevel)` — 15단계 R&D 시간 CSV에 연구소 레벨 보정 곱적용
10. **선술집 바운티:** `tavernBoardStore`의 `localBoard` 슬롯 수·갱신 주기를 레벨에서 동적으로 읽음
11. **스탯 상한 클램핑:** 모든 nudge 적용 후 `Math.min(stat + nudge, 100)` 강제 적용

### 신규 배치 함수 목록

```typescript
// 일 1회 배치에 추가
runFacilityStatNudgePass(planetId: string): void
  → 각 시설 레벨 조회
  → stat별 nudge 계산 및 클램핑
  → runPlanetPgpDailyPass 전 실행

runLaboratoryRdSpeedPass(planetId: string): void
  → 연구소 레벨 조회
  → 진행 중인 R&D 항목 효과 시간 보정

runTavernBountyRefreshPass(planetId: string): void
  → 선술집 레벨 조회
  → lastBountyRefreshTimestamp 기준 갱신 여부 판정
  → 슬롯 수에 맞게 바운티 보드 갱신
```
