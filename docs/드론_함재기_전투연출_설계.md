## 0. 한 줄

드론은 **접근 → 표적 원궤도 선회 → 들이받아 타격**이다.  
함재기는 **접근 → 일정 거리에서 8자 선회하며 일정 시간 공격 → 격추되거나 생존 시 모함 귀환**이다.  
현재 코드는 로켓 직선 스텁이다. **베지어 미사일 타입을 늘려 흉내 내지 않는다.** 선회체는 별도 **사전할당 크래프트 풀**로 복구한다.

---

## 1. 기획 의도 (대표님 정본 · 2026-08-23)

허브 인바운드 붉은 드론(행성 방사 접근)과 **다른 축**. 전함 슬롯 무기 `종류=drone` / `종류=carrier`만 해당.

### 1-1. 드론

1. 발사 함선에서 **표적 함선 쪽으로 비행**.
2. 표적에 붙으면 **표적 중심 원궤도**로 돈다.
3. 선회가 끝나면 **표적으로 파고들어 1회 타격**(자폭·충돌).
4. 탄이 아니라 **소형 기체**로 보인다. 한 번 때리면 소멸.

### 1-2. 함재기

1. 모함(발사 함선)에서 **표적을 향해 발진**.
2. 표적까지 **특정 거리**에 이르면 직진을 멈추고 **8자 선회 비행**.
3. 8자 구간에서 **일정 시간 반복 공격**(폭격·기총 — 한 방에 끝나지 않음).
4. 선회 중 **격추되면 그 자리에서 파괴**.
5. **시간이 끝나 살아 있으면 모함으로 귀환** 후 소멸(재사용 루프의 시각적 종료). 쿨다운이 돌면 다음 발진.

VMock 잔문: 드론 「표적 주위 궤도 선회」 · 함재기 「8자 선회 편대·모함 귀환」.  
정책 잔문: `orbit_loiter` / `arc_loiter_turn`. 정책 노트 「투하」는 함재기 **공격 페이즈**의 옛 별칭으로 보고, 대표님 루프(8자+시간공격+귀환)를 우선한다.

## 3. 왜 미사일 베지어를 쓰지 않는가

`Missile`은 `p0→p1→p2` + `travelMs` **일회 비행**이다.  
원궤도·8자·체공 사격·모함 귀환은 시간이 `travelMs`에 묶이지 않고, 표적·모함 위치를 **매 틱 따라가야** 한다.

| 방안 | 판정 |
|---|---|
| **1안 — `CapitalCraft` 사전할당 풀** | 채택. 페이즈·각도·잔여시간·HP를 슬롯에 둠 |
| 미사일에 phase 필드 추가 | 기각. 유도탄 핫패스와 선회체가 섞임 |
| 에이전트 함선으로 스폰 | 기각. STAGE3 함선 수·중첩 적분 폭주 |

구현 전까지 스텁(직선)은 그대로 둔다. 설계 확정 후 **스텁 분기를 교체**한다.

## 4. 상태기계

### 4-1. 드론 `orbit_loiter`

```text
APPROACH  →  표적까지 직선(또는 약한 곡선). 거리 ≤ orbitEnterPx
ORBIT     →  표적 중심 원궤도. 각속도 ω. 누적각 ≥ orbitLaps×2π 또는 orbitMs 경과
STRIKE    →  접선에서 표적 중심으로 돌입. 거리 ≤ strikeHitPx 이면 피해 1회 → DEAD
DEAD      →  슬롯 반환. hitApplied와 동일하게 탄두 즉시 비표시
```

- 표적이 선회 중 격침: **마지막 좌표에 고정** 후 STRIKE(허공 소멸 또는 잔여 돌입 — 구현 시 잔여 돌입 1안).
- 소유 함선 격침: 이미 나간 드론은 **그대로 끝까지**(발사체와 동일).
- 피해는 **STRIKE 착탄 1회**. ORBIT 중 지속 피해 없음(표 문구의 기관총·소사는 2차).

### 4-2. 함재기 `arc_loiter_turn`

```text
LAUNCH    →  모함 측면/선수 오프셋에서 출격
APPROACH  →  표적을 향해 비행. 거리 ≤ standoffPx 이면 FIGURE8
FIGURE8   →  표적 전방(또는 측면) 앵커에서 8자. 주기 T. 매 attackPeriodMs 마다 공격 틱
           잔여 engageMs 소진 또는 HP≤0 분기
RTB       →  생존·시간 종료. 모함 현재 좌표로 귀환. 거리 ≤ recoverPx → DEAD(회수)
DEAD      →  격추(HP≤0) 또는 회수. 슬롯 반환
```

8자 매개변수(슬롯 i, 시각 t, 반경 a, 주기 T):

```text
u = 2π t / T
x = a · sin(u)
y = a · sin(u) · cos(u)     //  lemniscate of Gerono
월드 = 표적 위치 + 회전(접근 접선) · (x, y) + standoff 오프셋
```

- **공격 틱**: FIGURE8 동안만. 표적 살아 있으면 `carrier_bomb` FX + 미사일 슬롯 피해(기존 `rollAgentWeaponDamage` + 상성).
- **격추**: 적 레이저/로켓/미사일이 크래프트에 맞으면 HP 감소. 1차 범위는 **근접 판정 원**(함선 히트박스보다 작게). 없으면 FIGURE8 종료=자동 RTB만(2차에 피격).
- **모함 이동**: RTB 목표는 **매 틱 모함 현재 좌표**. 베지어 고정점 금지.
- 표적 격침: FIGURE8 즉시 종료 → RTB.

## 6. 메모리·Skia (구현 시 헌법)

STAGE 3. 선회체는 고프레임이다. `arcfire-skia-memory-lifecycle` 그대로.

| 규칙 | 설계 |
|---|---|
| 할당 | 마운트 시 `CapitalCraft` 배열 **고정 길이** (drone 8 + carrier 8). 스폰=슬롯 활성화, 종료=`alive=false` |
| 틱 | 신규 `{}` / `.map` / `Path.Make` / `Paint()` 금지. 좌표는 슬롯 필드 변형 |
| 렌더 | 기존 전투 **단일 Canvas**. 크래프트는 **패밀리당 Path 1개** `rewind` 후 점/짧은 획 배칭. N개 `<Path>` 금지 |
| 탄두 | 원(드론)·짧은 타원(함재기). 트레일은 짧게 하거나 끔(로켓 테스트와 같이 헤드 우선 가능) |
| dispose | 전투 종료 시 루프 정지 → 슬롯 `alive=false` → Skia Path는 기존 풀과 같이 JS 클린업에서만 `dispose` |
| 상한 | `poolHardCap`. 초과 발사는 **스킵**(큐 남발 금지) |
| persist | 크래프트 **비영속**. STAGE 이탈 시 배열만 클리어 |

`missilesRef`와 **별 배열** `craftsRef`. VFX 예산의 미사일 카운트에 크래프트 수를 **더해** 동일 삭감 계단을 쓴다.

## 7. 전투 파이프 삽입점 (구현 순서 초안 · 코딩 금지)

1. `weapon_craft_loiter_policy.csv` + `build:balance-tables` (또는 content 빌드 슬롯 확정).
2. `CapitalCraft` 타입 + 고정 풀. `PlanetEdenRaidTestLayer` 틱에서 APPROACH/ORBIT/FIGURE8/STRIKE/RTB만 적분.
3. `buildCapitalProjectileSpawn`의 `orbit_loiter` / `arc_loiter_turn`을 **직선 폴백에서 풀 스폰으로 교체**.
4. 착탄: 드론=STRIKE 1회 `resolveCapitalWeaponImpact`(spread는 유지하되 1발). 함재기=FIGURE8 공격 틱마다 동일 롤 + `carrier_bomb`.
5. `PlanetEdenRaidOrbitSkiaCombat`에 크래프트 배칭 Path. `hitApplied`와 같이 **죽은 슬롯은 그리지 않음**.
6. 정책 `implementationStatus=active`. `isCapitalWeaponCombatActive`를 발사 게이트에 **실제로 연결**.
7. 게이트: `audit:skia-memory` · `tsc` · GL mtrack Δ±15MB · 허브↔전투 왕복 후 크래프트 0.

발사 쿨다운·사거리·대미지 가산은 **지금 WEAPON_2 미사일 경로와 동일**하게 읽는다. 바뀌는 것은 스폰 이후 궤적뿐이다.

## 9. 구현 전 잠금 체크 (대표님 확인용)

설계를 **완벽히** 끝내려면 아래만 막으면 코딩에 들어간다. 지금은 문서 기본값(§5)으로 적어 두었다.

1. 드론 선회는 **1바퀴 후 돌입**이 맞는지 (아니면 시간만).
2. 함재기 8자 공격은 **주기 피해**가 맞는지 (아니면 시각만 있고 피해는 귀환 직전 1회).
3. 함재기 **피격·HP**를 1차에 넣을지, 시각+귀환만 1차로 할지.
4. 동시 기체 상한 8 / 소유당 2 가 허브 궤도 5척 계약과 별개로 괜찮은지 (전투 STAGE3만).

위 네 줄이 확정되면 그때 구현 착수한다. **이 문서만으로는 코드·CSV를 올리지 않는다.**
