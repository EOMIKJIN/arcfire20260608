## 0. 한 줄

아크코어 엔티티 대화는 **부가 UI가 아니라 게임 핵심**이다.  
허브 **[대화]** · 전투 후 · (이후) 최초 실행 · 플레이 중 · 이벤트 · 특수퀘스트 · 미션이 **같은 전역 채널**로 이어진다.  
NPC는 기존 스크립트. 입은 대화, 몸은 운용. 피처는 **§0-C**. 등장 범위 잠금은 **§0-D**.  
스토리·퀘스트 GM은 **§0-G** — 입은 줄기만 이끈다. 수락·클리어는 몸(`missionStore`).  
스텔라 현장 메모(활성 의뢰·본편 세부)는 **`docs/STELLA_QUEST_FIELD_NOTE_v0.1.md`**. 근원체 줄기는 정체·12좌·리빌·운명만.  
고도화의 기본층은 **§0-H** — 일반 사람과의 일상 대화. 시스템 연동은 그 위에만.

## 0-A. 적정선 — 상용 유사(게임) / 실제 성능 아님 (2026-08-15)

대표님 지시: **실제 상용 에이전트 성능이 아니라**, 게임에서 그 창과 **비슷하게 느껴지는** 선까지.

### 0-A-1. 무엇을 닮고, 무엇을 포기하는가

| 상용에서 보이는 것 | 이 게임의 적정선 | 하지 않음 |
|--------------------|------------------|-----------|
| 열면 빈 창 + 인사 | **이미 잠금** — 히어로 인사, 세션 초기화 | 오픈 시 로그 전체 덤프 |
| 입력 캡슐 + 보조 슬롯 | **이미 잠금** — 흰 원형 1개, 아이콘은 자리만 | 슬롯에 실제 도구 실행 |
| 타이핑 출력 | **이미** — 글자 타이핑 | 토큰 스트리밍·네트워크 스트림 |
| 몇 턴이 이어짐 | **3~6턴 주제 유지** (세션 `topicStack` ≤4) | 100턴 장기 기억·계정 심리 모델 |
| 지금 상황 질문 | **관측한 스칼라만** (위치·스파이·전투 1·코어 5·공지 1) | 웹검색·전 은하 RAG |
| 모르면 모른다고 | 물은 **세계 축**에만 「그 관측은 없다」. 일상 말은 잡담 (§0-H) | 없는 함선·퀘스트·숫자 창작 · 잡담에 「관측 없다」 |
| 해 달라는 부탁 | **거절** (입≠몸) | 배치·언락·크레딧·점유 |
| 최근 대화 | 「최근항목」 **추후** | 무한 스크롤 히스토리 |
| 똑똑한 문장 | 로컬 1축이 **하한=본선**. 클라우드는 있으면 가산 | 클라우드 필수·온디바이스 LLM |

플레이어가 「접수 창구 버튼」이 아니라 **같은 창에서 되받는 상대**로 느끼면 적정선이다.  
벤치마크·토큰 품질·멀티홉 도구 루프는 이 게임의 목표가 아니다.

### 0-A-2. 지금 배와 갭

| 층 | 지금 (2026-08-21) | 적정선 | 갭 |
|----|-------------------|--------|-----|
| 셸 | 세션 리셋·히어로·흰 캡슐·글자 타이핑 | 유지 · 문장 분할 리듬은 §0-F H3 | 최근항목만 추후 |
| 분류 | 토픽 CSV + 정규식 힌트 | 힌트만. 생성의 전부 아님 | 충분 |
| 세션 기억 | `topicStack` 4 + `lastArcQuestion` + `rollingSummary` 400 | 유지. 벡터 DB 없음 | **태그 구조화만** §0-F H1 |
| 관측 | 팩 도구 ≤4 + 코어·공지 | 현재 행성 스칼라만 | 충분 |
| 발화 | 팩 한 축 · 클라우드는 LIVE=false | 온라인+키면 F1 | **토큰 수령 후 LIVE** |
| 검역 | 500자 · 운용 · 섀도우 · 신설 | 유지 | 충분 |

정규식 6키를 늘리는 작업은 고도화가 아니다. 창구가 커질 뿐이다.

### 0-A-3. 본선 / 후속

| 구분 | 내용 |
|------|------|
| **자연어 성립** | **F1** 클라우드 LLM. 없으면 창구. §0-C |
| **세계·생존** | **F2 팩 + F4 검역 + F5 로컬 폴백**. 오프라인은 창구로 내려감 |
| **하지 않음** | 13좌, 온디바이스 LLM, 클라 벤더 SDK, 월드 write 툴, 틱 사고, 모드 A(로컬 초안 윤색만) |

v1.0의 「모드 B(클라우드 생성)가 본선」은 **철회**한다. 모드는 후속이다.

### 0-B. 자연 대화 판정 (2026-08-15 재검토)

질문: **지금(또는 G3만으로) 자연스러운 대화가 가능한가.**

| 대상 | 판정 | 한 줄 |
|------|------|--------|
| **지금 배** | **복도만 조건부 예** | 같은 세션에서 팩 토픽·코어·공지/미션을 로컬이 읽음. 열린 자연어는 F1 |
| **G3 본선** | **로컬 장착 (2026-08-21)** | 「그건?」은 직전 축. 안전은 D가 있을 때만. 창 닫으면 스택 리셋(잠금) |
| **상용과 같은 자연스러움** | **아니오 · 목표 아님** | 온디바이스/클라우드 실성능 없이 불가능하고, 이 게임은 그걸 요구하지 않음. |

**지금 배가 받는 문장 (2026-08-21)**

| 유저 | 결과 |
|------|------|
| 거긴 안전한가? | 토픽 `safety` · 코어 D 있으면 그 값, 없으면 「관측 없다」 |
| 그건? / 왜? / 응 (같은 세션) | 팩 `topicStack` 직전 축으로 회신 |
| 날씨 어때 | 일상 잡담 — 사람처럼 받고 세계 브리핑을 하지 않는다 (§0-H) |
| 여기 어디야? → (창 닫고 다시) 거긴? | 세션 리셋 · 스택 없음 (잠금). 요약 태그만 persist |

**G3가 채우는 자연스러움 (복도)**

1. 직전 아크 질문 + `topicStack` — 「응/그건/왜/거긴」을 직전 축에 붙인다.  
2. 토픽 `safety` + 코어 D — 「안전한가」가 other가 되지 않는다.  
3. 지식 카드 1장 — 「넌 누구냐」에 창구 안내가 아니라 정체 한 축.  
4. 물은 세계 축에 관측이 없을 때만 「그 관측은 없다」. 일상 말의 기본 회신은 잡담이다 (§0-H).

이 네 개가 있으면 §3-1 **복도**는 로컬로 통과한다. 처음 보는 문장·잡담·비유를 사람처럼 받는 것은 **LLM이 필요**하다(§0-C F1). 관측 없는 **세계 축**을 지어내는 것은 자연스러움이 아니다. 일상 말에 「관측 없다」를 쓰는 것도 자연스러움이 아니다.

**자연 대화로 착각하면 안 되는 것**

- 타이핑·흰 캡슐·인사 = 창의 자연스러움. **말의 자연스러움이 아님.**  
- i18n 키를 20개로 늘림 = 창구가 커질 뿐.  
- 클라우드 없이 「사람처럼 아무 말이나」= **불가** (2026-08-15 재확인).

## 0-C. 실기동 조건에서 필요한 피처 (2026-08-15 재조사)

게임에서도 자연스러운 AI 채팅이 되려면 산업(Inworld·Xbox NEO·Origins)은 층을 많이 판다.  
아래는 **아크파이어가 지금 돌아가는 조건**으로만 다시 추린 것이다. 일반 에이전트 위시리스트가 아니다.

### 0-C-1. 이 게임이 이미 강제하는 조건 (빼면 헌법 위반)

| 조건 | 실기동 | 피처에 미치는 영향 |
|------|--------|-------------------|
| 싱글·오프라인 월드 | ArcCore가 로컬. Firestore는 프로필 단발 | 채팅이 꺼져도 세계는 돈다. **오프라인 폴백 필수** |
| RN / Expo / 모바일 | STAGE 1 허브 위 `ArcOverlayHost` | Unity/Unreal SDK·C++ Runtime **불가** |
| 시작 화면 최소 활성 | 버튼은 hydrate만. 배치는 차원항로 | 채팅·LLM·Functions **타이틀 대기 금지** |
| 입 ≠ 몸 | 12좌·일일배치·AABS는 서브코어 | 채팅에 write 툴·명령버스 **없음** |

| Auth는 이미 있음 | `ensureFirebaseAnonymousAuth` · 실패 시 로컬 계속 | Callable은 uid. 없으면 클라우드 스킵 |
| AWS 문장 홉 | `aws/arc-core-chat` · `LIVE=false` | 키/URL 없으면 F5. 클라 AWS SDK 없음 |
| PSS | 오픈 1 / 전송 1 | 틱 사고·전 행성 RAG·80전 디스크 **금지** |
| NPC | `NarrativeDialog` | 전 NPC LLM화 **금지**. 아크코어 채널만 |
| 섀도우 | 리빌 전 닉 금지 | 팩에 `revealShadow:false` |
| 전투 | Skia dispose 전 오버레이 금지 | 채팅은 결과 닫힌 뒤 |

### 0-D. 전역 핵심 — 아크코어 엔티티 대화 (2026-08-16 잠금)

대표님 잠금: 아크코어 엔티티 대화는 **게임 프로세스 전체의 핵심**이다.  
고도화·완성도의 방향은, 플레이어와 **같은 채널에서 대화를 이어 가는 것**이다. 허브 부가 창이 아니다.

| 등장 | 상태 |
|------|------|
| 허브 [대화] · 에이전트 컨택트 | **실기동** |
| 웨이브 전투 후 `combat_end` | **실기동** — 결과 닫힌 뒤. `triggerId=wave:{planetId}`라 **같은 행성 자동 채널은 1회** |
| 허브 선제 요청 `inbound_request` | **실기동** — 착륙 허브·슬롯 안전일 때만. 첫 45–90초, 이후 8–15분. 수락 Alert → 같은 채널. **수락 후 클라우드 질문 1개**(실패 시 로컬 질문 폴백). 푸시·백그라운드 금지 |
| 최초 앱 실행 (부트 전면 채팅) | **플래그 OFF** — `ARC_CORE_BOOT_CHAT_FIRST=false`. 타이틀 버튼은 즉시. 선실행은 `docs/ARC_CORE_BOOT_CHAT_FIRST.md` 예약만 |
| 게임 진행 중 | **방향 잠금 · 고도화** — 선제는 inbound가 1차. 백그라운드 푸시는 §0-F 후속 |
| 이벤트 · 특수퀘스트 · 미션 | **방향 잠금 · 고도화** — 기존 NPC 스크립트와 동시 스택 금지. 스크립트 dismiss 후 같은 API |

이미 있는 입구만 쓴다: `presentArcCoreBackchannel`. 화면마다 창을 복제하지 않는다.  
입≠몸 · 12좌 · 온디바이스 LLM 금지 · PSS(오픈/전송 1 · inbound 수락 1)는 유지.  
지금 전투 후 등장은 **확인 완료**. 위 슬롯을 늘리는 구현은 **추후 고도화 지시** 후.

### 0-E. 이중세계 — 현실 에이전트 ≠ 아크코어 에이전트 (2026-08-20 검토)

대표님 정의: **현실세계 = 기존 상용 에이전트**, **아크코어 게임세계 = 아크코어 에이전트**.

## 0-H. 일상 대화가 기본 — 시스템 연동은 그 위 (2026-09-09 잠금)

대표님 지시: 아크코어 대화의 고도화는 **시스템과 연동 위에, 일반 사람과의 자연스러운 일상대화를 기본**으로 구축한다.

시스템 팩트·도구·시설 제안은 대화의 바닥이 아니다. 사람은 먼저 말을 받고, 세계 축은 그 사람이 묻거나 정세를 찾을 때만 올라간다.

```text
[pss-pre-dev] hot_path=전송 1회 + inbound 수락 1회 alloc=팩 1 + 도구≤4 + 이력 스칼라 cache=기존 chat persist
[pss-pre-dev] stage=overlay · 허브 opener 등록만 · 틱/부트 hydrate 없음
[pss-pre-dev] verdict=PASS — 월드 write·경제 store·13좌 없으면 착수
```

| 층 | 언제 | 하는 일 | 하지 않는 일 |
|----|------|---------|--------------|
| **0 일상 (기본)** | 인사 · 기분 · 잡담 · 열린 기타 · 직전 축 추임새 | 사람처럼 이어 받는다. `invite_axis` · `react` · `nextAsk=''` | 전투·채굴·일일·무역소·조선소로 가로채기. 「관측되지 않았다」 |
| **1 시스템 (위)** | 위치·스파이·전투·안전·공지·미션·스토리·채굴·일일·정체를 **명시**. 「그건?」은 직전 세계 축 | 물은 축만 `react`. 관측 없으면 그 축에 한해 「없다」 | 지난 무역소 수락을 `nextAsk`에 실어 다른 말에 끼워 넣기 |
| **1 정세 (위)** | 「요즘 / 무슨 일 / 별일 / 현황 / 정세」 | 사람 말 **뒤에** 단서 하나(`clue`/`lead`) | 사람 문장을 시스템 템플릿으로 **교체**. 기분 질문에 시설 확인창 |

금지 유지: ObservationBus · learning-state · 일일 배치 실행 · 13좌 · 온디바이스 LLM · 경제 store write · 미션 수락/클리어.

성공: 「오늘 기분이 어때」에 무역소·전투가 나오지 않는다. 「오늘 뭐 했어」에 「관측되지 않았다」가 나오지 않는다. 「여기 어디야?」는 행성만. 「요즘 무슨 일 있어?」만 세계 단서를 사람 말 뒤에 붙인다.

### 3-3. 유사 충분 (완벽을 기다리지 않음)

- 모든 문장이 인간 작문일 필요 없다.  
- **LIVE 전 로컬 복도가 하한.** 클라우드가 있으면 같은 팩으로 문장만 가산. 주제가 이어지면 합격.  
- 멀티홉 도구 루프·장문 RAG·감정 시뮬레이션·실제 LLM 벤치는 넣지 않는다.

## 4. 한 턴 루프 (LLM 에이전트를 흉내 내는 본문)

채널 `submit`은 유지한다. 회신 내부를 이 루프로 교체한다.

```text
유저 한 줄
  1. 주제 힌트 (토픽 CSV + 키워드. 실패해도 진행)
  2. ReadTools ≤4 (힌트된 것만. 항상 전 도구 실행 금지)
  3. 지식 카드 ≤4 (speakIf + topic)
  4. ContextPack 조립
  5. Provider.complete(pack)
       cloud  → Functions 1회 → 서비스 LLM (사고+발화)
       local  → 팩으로 한 축 조립 (폴백)
  6. 검역 (500자 · 금지 토큰 · 섀도우 · 신설 아이템/퀘스트)
  7. 검역 실패 또는 타임아웃 → local 재조립 1회
  8. rollingSummary 덮어쓰기 (400자) · topicStack 갱신 (≤4)
  9. 스토어 append (40/500)
```

```text
클라 --(팩, 벤더 모름)--> Functions --(Secret)--> 서비스 LLM
클라 <--(text)----------- Functions
```

| 해야 할 일 | 하지 말 일 |
|------------|------------|
| 한 질문 → 한 축 | 매 턴 전 팩트 덤프 |
| 팩트·카드에 있는 것만 말함 | 추측으로 세계 창조 |
| 도구는 읽기만 | `dispatch` / unlock / credit |
| inFlight 1 · 타임아웃 후 폴백 | 스트리밍 · onSnapshot · 동시 N요청 |
| 전송 1회만 팩 조립 | 틱/부트/prewarm에서 모델 호출 |

모드 A(로컬 초안을 클라우드가 윤색만)는 쓰지 않는다 — 지능이 초안에 갇힌다.  
모드 C(월드 write 툴)는 금지.  
모드 L(로컬 1축 조립)이 **게임 본선**. 모드 B(클라우드 생성)는 **후속 가산**.

## 9. 로컬 1축 조립 (본선 · 지능이 아님 · 게임 유사 충분)

클라우드 없거나 실패여도 **이 경로가 답이다.** 같은 팩으로:

1. 정책 `refuse` → 거절 한 줄.  
2. 도구가 직접 답함 (위치/스파이/전투/코어) → 그 축 한 줄 + 필요 시 짧은 물음.  
3. 지식 카드 1장이 주제와 맞음 → 카드 문장(토큰 치환).  
4. 아크가 물은 것에 유저가 답함 → 요약에 반영하고 다음 한 축.  
5. 그 외 → 일상 잡담으로 이어 받는다. 물은 세계 축에 관측이 없을 때만 「없다」. **브리핑 3줄 묶음 금지.**

이미 같은 주제를 답했으면 짧은 추임새(`greetAgain` 류) 후 **다음 한 축**을 묻거나 관측을 닫는다.  
이 경로가 오프라인·개발·타임아웃·**출시 하한**이다.

세계 콘트롤 B안(입 제안)과 **다른 축**. NCP 코드·`CLOUD_LIVE`·NCP 키는 대표님 **별도** 지시 전 **금지**(A안 막힐 때만 재검토).

**가드 (연동해도 유지)**

- 클라 SDK/키 없음 · 13좌 없음 · 월드 write 툴 없음  
- 입≠몸 — 모델에 dispatch/unlock/credit 도구를 주지 않음  
- 오프라인·타임아웃 = 로컬 본선  
- **팩(G3) 없이 API만 열면** 모델이 세계를 지어낸다. 파이프는 돼도 검역·관측 팩이 선행이다.

**산업 관례:** 커서·챗앱·AI 동반 게임이 쓰는 것과 **같은 모양**이다.  
앱(채팅창) → **자사 백엔드** → 클로드/제미니/베드록. 키는 앱에 없다. 커서가 클로드 창을 쓰는 것도 이 홉이다.  
다른 점: 커서는 스트리밍·도구 루프가 본업. 아크파이어는 게임이라 **1회 완성 문장 + 오프라인 로컬 본선**이 다르다. 벤더를 앱에 심는 방식은 상용에서도 쓰지 않는다.

### 12-B. 학습 — Inworld AI가 게임에서 쓰는 방식 (2026-08-15)

공개 자료(제품 페이지·Runtime 문서·Xbox/Ubisoft/NVIDIA 발표·Origins 리뷰)만. **SDK 도입·벤더 계약 아님.** 패턴만 가져온다.

#### 12-B-1. 한 줄

Inworld는 **채팅봇이 아니라 캐릭터 파이프**다. 말(STT→LLM→TTS)과 **게임 상태(장면·지식·목표·트리거·감정→애니)** 를 한 그래프에 묶는다. 2025~26 제품은 예전 Character Engine을 **Runtime(C++ 그래프) + Realtime API + LLM Router** 로 재포장했다.

#### 12-B-2. 게임이 실제로 붙이는 층

```text
플레이어 말/타이핑
  → STT (말의 감정·속도·피치까지 신호)
  → 캐릭터 카드 (성격·무드·지식·목표·장면)
  → Knowledge 검색 (에디터에서 컴파일, 런타임 시맨틱)
  → Safety (토픽 임계)
  → LLM Router (bark=싼 모델 / 컷신=비싼 모델)
  → 목표 매칭 (Verbatim=고정 대사 / Instruction=지침)
  → TTS + viseme/타임스탬프
  → 엔진: 감정 라벨 → 애니 트리, SendTrigger → 퀘스트/문/이벤트
```

| Inworld 모듈 | 게임에서 하는 일 | 아크파이어 대응 |
|--------------|------------------|-----------------|
| Character card (traits/mood/scene) | NPC가 **누구인지·어디인지**를 프롬프트에 고정 | persona + 관측 스칼라 CSV |
| Knowledge + KnowledgeFilter | 알 수 있는 사실만 검색. 필터로 숨김 | knowledge CSV + ContextPack 화이트리스트 |
| Goals (`Verbatim` / `Instruction`) | 키워드·인텐트면 **고정 대사** 또는 **지침** | i18n 고정 vs 로컬 1축 조립 |
| `SendTrigger(goal, params)` | 게임이 **이벤트**를 캐릭터에 주입 (문 열림, 퀘스트) | 읽기 도구 ≤4. **월드 write 금지** (입≠몸) |
| Emotion / Relation | 기쁨·신뢰 등을 애니·말투에 연결 | **하지 않음** (적정선 밖) |
| Safety + embedder | 입·출 모두 토픽 임계 | 검역 (금지 토큰·섀도우) |
| Memory retrieval | 세션 너머 기억 | topicStack 4 + 요약 400 (G4) |
| Realtime STT/TTS / barge-in | 마이크 대화가 플레이 | **텍스트 창**. 음성은 후속 아님 |
| LLM Router (220+) | 장면·동시 NPC·로케일로 모델 분기 | Functions Secret `vendor` + 로컬 폴백 |
| Filler ("잠시만요") | 본 LLM이 늦으면 같은 목소리로 메움 | 타이핑 연출만. 필러 LLM 없음 |
| Runtime graph (Remote/Local) | 클라우드 또는 온디바이스 노드 | **온디바이스 LLM 금지**. 로컬=규칙 조립 |
| API 키 | 서버 Basic / 클라 JWT (백엔드 발행) | Functions Secret. 클라 키 없음 |

#### 12-B-3. 스튜디오가 보여 준 쓰임

| 사례 | 무엇을 했는지 | 우리와의 거리 |
|------|---------------|---------------|
| **Origins** (자사 데모) | 탐정 심문. **대화 자체가 플레이**. 목격자마다 지식·동기가 다름 | 아크코어 1채널·관측만. 심문 미니게임 아님 |
| **Ubisoft NEO NPC** (GDC 2024 프로토) | 음성으로 말 → 스토리 조각·퀘스트 생성. NVIDIA Audio2Face | 프로토. AAA 본편 미탑재. 퀘스트 생성은 우리 금지 |
| **Xbox × Inworld** | **디자인 코파일럿**(스크립트→분기 그래프) + **런타임 캐릭터 엔진** | 이원화. 우리는 런타임 입만. 코파일럿은 제작툴 |
| **NVIDIA Covert Protocol** | ACE + 하이브리드 온디바이스/클라우드 | 모바일 RN. 온디바이스 모델 헌법 금지 |
| **Niantic / 8th Wall** | AR 공간 캐릭터 | 허브 오버레이와 무관 |
| **NetEase / 모드** (Skyrim·GTA·Stardew) | 기존 월드에 AI 주민을 얹음 | 모드·쇼케이스. 출시 본편의 표준은 아님 |
| **Streamlabs** | 방송 어시스턴트 | 게임 NPC 아님 |

**사실:** 2026 기준으로 Inworld는 **출시 AAA의 기본 대화 엔진**이 아니라, 프로토·파트너십·보이스/라우터 인프라로 쓰인다. 「Inworld를 넣으면 상용 NPC」가 아니다.

#### 12-B-4. 게임이 챗봇과 다르게 쓰는 이유 (가져올 것)

1. **세계가 먼저다.** 장면·지식·트리거를 게임이 넣고, LLM은 그 안에서만 말한다. 팩 없이 API만 열면 환각 — 우리 §12-A와 동일.
2. **고정 대사와 생성의 혼용.** Goal `Verbatim`은 중요 비트를 스크립트로 잠근다. 전부 생성하지 않는다. 우리 i18n 고정 + 1축 조립과 같다.
3. **입은 말, 몸은 엔진.** 감정·트리거는 **게임이 실행**한다. Inworld도 문을 직접 열지 않고 `SendTrigger`로 알린다. 우리는 한 단계 더 막아 **읽기만**.
4. **모델은 한 종류가 아니다.** bark / 동반 / 컷신을 나눈다. 우리는 로컬 본선 + (후속) 클라우드 1종으로 충분.
5. **지연을 숨긴다.** 필러·스트리밍 첫 오디오. 우리는 타이핑으로 같은 느낌을 낸다.
6. **키는 서버.** 브라우저/클라 JWT, 서버만 원키. 우리 Functions와 같음.
7. **관측·실험.** 그래프를 재배포 없이 바꾸고 지연을 잰다. 우리는 CSV+검역이 그 자리.

#### 12-B-5. 가져오지 않을 것 (잠금 유지)

| Inworld가 파는 것 | 이유 |
|-------------------|------|
| Unity/Unreal SDK · C++ Runtime을 앱에 심기 | RN/Expo. 네이티브 그래프는 STAGE·PSS 위험 |
| 온디바이스 LLM | 헌법 · 시작화면·허브 메모리 |
| 음성 STT/TTS · barge-in · viseme | 텍스트 채널 적정선 |
| 감정·관계 슬라이더 · 그룹 대화 | 아크코어 1인칭 접수 창구 |
| 대화로 퀘스트/문/월드 write | 입≠몸 |
| 전 NPC Inworld화 | 허브 NPC는 기존 스크립트. 아크코어만 채널 |
| Inworld를 벤더로 직접 호출 | 후속은 구글/AWS Functions. 라우터를 또 끼우지 않음 |

#### 12-B-6. 이 학습이 바꾸는 것 / 안 바꾸는 것

- **안 바꿈:** 본선=로컬 G3, 클라우드=가산, 온디바이스 금지, 입≠몸, 12좌.
- **확인만:** G2 지식 CSV + G3 팩 + 검역이 Inworld Knowledge/Safety/Goal과 **같은 자리**다. 상용 게임도 LLM 앞에 이 층을 둔다.
- **구현 지시 없음.** 본 절은 학습. G1부터는 대표님 지시 후.

## 15. 구축 순서 (적정선 = G3까지 · 클라우드 없이 완료 선언 가능)

템플릿 키만 늘리는 작업은 하지 않는다.

| 단계 | 산출 | 플레이어가 느끼는 것 | 적정선 |
|------|------|----------------------|--------|
| **G0** | 셸 (세션 리셋·히어로·캡슐·커서) | 상용 창 | **함** |
| **G1** | 세션 `topicStack` 4 + `lastArcQuestion` (RAM, 오픈 시 리셋) | 3~6턴이 이어짐 | 필수 |
| **G2** | persona/topics/knowledge CSV + 인덱스 | 주제가 6키를 넘음 | 필수 |
| **G3** | Pack + ReadTools≤4 + 로컬 1축 + 검역 | **오프라인 합격 = 출시 하한** | **여기까지가 본선** |
| **G4** | persist v2 요약 (최근항목·재방문 톤) | 창을 닫아도 결이 남음 | 후속 |
| **G5** | Functions + cloud Provider | 문장이 더 사람다움 | 가산 · 없어도 완료 |
| **G6** | 타임아웃/쿼터 → G3 | 세계는 멈추지 않음 | G5와 세트 |

G3만으로 §3-1과 §0-A 성공 기준을 채우면 **고도화 1차를 완료**한다.  
G5를 기다리지 않는다. G5 없이 「에이전트 미완」을 선언하지 않는다.

구 표기 S1–S5는 G2–G6에 대응한다. S3=G3이 본선인 점은 같고, S4=G5는 본선이 아니다.
