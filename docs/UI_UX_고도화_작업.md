## 0. 한 줄

아크파이어 허브의 **빈 상·하단 밴드**를, 일반 상용앱이 쓰는 고정 네비 비율로 채운다.  
게임 도크(스캔·시설·파일럿)는 유지한다. 아이콘은 1차에서 임시(Ionicons)다.

---

## 1. 기획 의도

원하시는 것은 새 게임 시스템이 아니라, **앱을 켠 뒤에도 완성된 상용앱처럼 보이게 하는 고정 크롬**이다.

| 지시 | 해석 |
|------|------|
| 실행하면 고정 네비 | 화면 위·아래에 **항상 보이는 앱 셸**. 본문(행성·궤도)은 그 사이 |
| 상단 = 가운데 제목 + 좌·우 각 1개 | 장소형 캡처의 3슬롯이 정본. 스토리형처럼 왼쪽 탭 2개·오른쪽 아이콘 3개는 **쓰지 않음** |
| 하단 = 중요 기능 3~5개, 아이콘+라벨 | 장소형 **5탭 풀폭**이 밀도·폭의 표준. 스토리형은 4탭·플로팅 캡슐(미감 참고만) |
| 공백에 채워넣는다 | 허브에 **이미 있는 빈 밴드**를 탭/탑바로 채움. 도크를 지우고 대체하지 않음 |
| 임시 아이콘 | 1차는 Ionicons 자리표시. 기능 확정·전용 아트는 나중 |
| 상용 폭에 가깝게 | 터치 44, 상단 콘텐츠 44~48, 하단 아이콘+라벨 56~64 + 홈 인디케이터 |

의도는 **게임 HUD를 앱 내비게이션처럼 보이게 하는 것**이다.  
인스타형 전 앱 탭으로 STAGE 2·3까지 덮는 것이 아니다.

---

## 2. 참고 상용앱 — 가져올 것 / 버릴 것

### 2-1. 장소형 캡처 — 구조 정본

- 상단 3슬롯: 왼쪽 보조 1 · **가운데 제목** · 오른쪽 보조 1
- 하단 5탭: 아이콘 위 / 라벨 아래, 균등 폭, 활성만 강조색
- 본문과 하단 사이 **얇은 구분선**
- 검색바·칩·카드는 **이번 범위 밖** (허브 본문은 행성 시야)

### 2-2. 스토리형 캡처 — 밀도·여백만

- 하단 아이콘+라벨, 활성 시 약한 하이라이트
- 좌우·하단 여유(숨 쉬는 패딩)
- 가져오지 않음: 왼쪽 텍스트 탭 2개, 오른쪽 유틸 3개, 검색+칩, 흰 배경 전체

아크파이어는 우주 허브라 **바 자체는 기존 전술 톤(반투명 다크)** 을 유지한다.  
흰 슬래브로 성운을 덮지 않는다.

## 3. 현재 허브와의 차이 (왜 공백으로 보이는지)

정본 레이아웃: `src/stages/planetMainStageLayout.ts`  
탑바 실스타일: `src/components/planet/planetHub/planetHubStyles.ts`  
허브 화면: `app/(game)/planet.tsx`

### 3-1. 상단

이미 3슬롯이지만 상용과 다르다.

| 항목 | 현재 |
|------|------|
| 왼쪽 | 고정폭 112 — 종료 · 설정 · 랭킹 **3개** |
| 오른쪽 | minWidth 128 — 보석 · 크레딧 **칩 2개** |
| 가운데 | `planet.mainStage` 제목. 양쪽에 밀림 |
| 아이콘 한 변 | `PLANET_MAIN_TOPBAR_ICON_BUTTON_PX` = **34** (상용 히트 44보다 작음) |
| 퀘스트 HUD | 탑바 **아래**. 게임 본문이지 네비가 아님. **유지** |
| 시각 lift | `PLANET_MAIN_FOREGROUND_TOP_CHROME_LIFT_PX` = 10. 레이아웃 높이·배경 패딩과 분리 |

### 3-2. 하단 (위에서 아래)

| # | 층 | 성격 |
|---|-----|------|
| 1 | 스캔 5열 — 행성개발 · 채굴 · 대화 · 수색 · 스캔 | 행성 안 조작 도크 |
| 2 | 시설 5열 — 무역소 · 조선소 · 바 · 연구 · 출발 | 행성 안 조작 도크 |
| 3 | 파일럿 헤더 44 | 도크 |
| 4 | `PLANET_MAIN_BOTTOM_FEATURE_RESERVE_PX` = **140** | **빈 공백 — 이번 작업이 채울 자리** |
| 5 | 홈 인디케이터 (safe area) | 시스템 |

1·2·3은 상용 하단 탭과 역할이 다르다.  
여기를 탭바로 갈아끼우면 스캔/시설이 사라진다.

## 4. 권장 1안

**허브 STAGE 1만. 도크는 유지. 빈 밴드만 크롬.**

```text
[상태바]
[상용 상단]  [설정]     행성명/메인스테이지     [재화 1묶음]
[퀘스트 HUD]  ← 기존 유지, 탑바 높이 상수 식과 동기
[행성·궤도 시야]
[게임 도크]   스캔 5 + 시설 5 + 파일럿   ← 기존 유지
[상용 하단]   탭 5 (임시 아이콘)         ← 140 예약을 이 높이로 사용
[홈 인디케이터]
```

### 4-1. 화면 범위

| 화면 | 이번 계획 |
|------|-----------|
| STAGE 1 허브 | 상·하단 크롬 적용 |
| 타이틀 | **넣지 않음** (이어하기 즉시 활성 계약) |
| 월드맵 · 전투 | **넣지 않음** (`replace` · Skia · 채팅 overlay dismiss와 충돌) |
| 무역/조선 등 시설 | 1차는 허브만. 시설은 기존 하단 spacer 규칙 유지 |

앱 전체에 탭을 고정하는 것은 루트 호스트 + STAGE마다 dispose가 필요해서, 이번 의도와 PSS와도 맞지 않는다.

### 4-2. 상단 슬롯 (장소형 구조)

| 위치 | 1차 | 지금 버튼은 |
|------|-----|-------------|
| 왼쪽 1 | 설정 | 종료·랭킹은 설정 패널/기존 오버레이로 접음 (종료는 설정에 이미 있음) |
| 가운데 | 제목 1줄 (현 `메인스테이지` 또는 행성명 — 구현 시 문구는 기존값 유지가 안전) | 그대로 중앙 |
| 오른쪽 1 | 재화를 **한 묶음**(크레딧 우선, 보석은 같은 칩을 누르거나 상점) | 칩 두 개의 가로 폭을 줄여 “기능 1개”로 보이게 |

아이콘은 임시 Ionicons.  
박스 보더 3개를 나열하지 않고, 좌우 **여백을 넓게** 잡아 장소형처럼 숨 쉬게 한다.

### 4-3. 하단 탭 5 (임시, 허브 안에서만)

도크와 **겹치지 않는** 앱 축만 둔다. 1차 탭은 **허브를 떠나지 않음**.

| # | 라벨(안) | 임시 아이콘 | 1차 동작 |
|---|----------|-------------|----------|
| 1 | 허브 | home | 현재 화면, 활성 |
| 2 | 통신 | chatbubble | 기존 `[대화]`와 동일 채널 (`presentArcCoreBackchannel`) |
| 3 | 지휘 | person | 설정 또는 파일럿 펼침 |
| 4 | 보급 | cart | BM 상점 오버레이 |
| 5 | 기록 | podium | 기존 점유/랭킹 오버레이 |

**항로(월드맵)** 는 2차에 둔다.  
지금은 출발 타일이 있고, 탭에서 `replace`하면 STAGE 이탈·채팅 닫힘·Skia freeze가 한 번에 붙는다.

활성 탭만 전술 액센트, 나머지는 낮은 잉크.  
아이콘 위 · 라벨 아래 · 5등분.

### 4-4. 상용 치수 목표

| 항목 | 상용 대략 | 현재 | 1안 |
|------|-----------|------|-----|
| 상단 히트 | 44 | 아이콘 34 | 좌우 슬롯만 44에 가깝게. **탑바 총높이는 배경 `paddingTop`과 같이 움직여야 함** |
| 상단 콘텐츠 | 44~48 + safe top | ≈49 + lift 10 | 비율만 맞춤. `TOP_CHROME_LIFT`는 **기본 유지** |
| 하단 탭 콘텐츠 | 56~64 | (없음) | 아이콘 ~24 + 라벨 + 패딩 ≈ 56~64 |
| 하단 + 홈 인디케이터 | ≈83~98 | 예약 140 + safe | **140 예약을 탭 자리로 씀.** 숫자는 1차에서 바꾸지 않음 |
| 탭 구분 | 헤어라인 | 없음 | 도크와 탭 사이 1px |

140이 탭(~64+safe)보다 크다.  
1차는 **여분을 스크롤 마지막 spacer로 남겨** 행성이 위로 밀리지 않게 한다.  
예약을 줄이는 것은 **기존값 변경**이라 구현 전에 대표님 재확인이 필요하다.

**구현 전 미결 (기존값 재확인)**

- 탑바 아이콘 34를 상용 44에 맞출지, 지금은 34를 유지한 채 슬롯만 줄일지
- 하단 140은 1차에서 **숫자를 바꾸지 않음**이 기본

## 5. 헌법 · 메모리

- `PLANET_MAIN_BOTTOM_FEATURE_RESERVE_PX` · `PLANET_MAIN_FOREGROUND_TOP_CHROME_LIFT_PX` · 탑바 34 · 퀘스트 HUD 추정 **무단 변경 금지**. 바꾸면 궤도/배경이 세로로 흔들린다.
- 하단 탭을 ScrollView **밖** 고정 블록으로 뷰포트를 줄이는 방식은 금지. 정본은 **지금처럼 스크롤 하단 예약과 같은 높이 예산**을 쓰는 것. 탭을 시각적으로 하단에 붙이려면 `paddingBottom`과 배경 `paddingBottom`을 **같은 식**으로만 맞춘다.
- 시설 화면 하단 spacer는 계속 이 예약값을 공유한다. 탭을 시설에 안 그려도 숫자는 맞아야 한다.
- 알림은 `ArcOverlayHost`만. 탭마다 RN `Modal` 금지.
- 레이아웃 `top`/`left` 애니 금지. `transform`만.
- 월드맵 「고착 방지」 안전망 금지 (2026-08-02 교훈).

## 6. 작업 순서 (승인·지시 후)

1. **기존값 재확인** — 탑바 아이콘 34→44, 예약 140 유지 vs 축소. 승인 전에는 스타일·슬롯 정리만.
2. **상단 슬롯 정리** — 좌 1 · 제목 · 우 1. 종료/랭킹/보석 이관 위치만 연결. 신규 persist 없음.
3. **하단 탭 셸** — 140 밴드에 5칸 임시 아이콘+라벨. 허브·통신·지휘·보급·기록. 항로 없음.
4. **동기** — `paddingBottom` / 배경 크롬 / 퀘스트 HUD 추정. 행성 도트 Y가 바뀌면 실패.
5. **게이트** — `tsc` · `audit:memory:all`. Skia 루프는 건드리지 않음. 실기는 허브 왕복 후 행성 위치·Views.
6. **2차 (별도 지시)** — 탭 기능 확정, 전용 아이콘, 항로 탭, 예약 140 축소 여부.

## 7. 일부러 안 하는 것

- 타이틀·월드맵·전투에 같은 탭
- 스캔/시설 5열을 탭바로 흡수
- 검색바·카테고리 칩·흰 배경
- 월드맵 고착 안전망
- LIVE/채팅 입구 추가 (통신 탭은 **기존 채널만**)
- 본 문서만으로 코드 착수 (대표님 구현 지시 필요)
