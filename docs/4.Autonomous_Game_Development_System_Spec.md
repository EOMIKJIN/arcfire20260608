# [최종] 아크파이어 온라인: 자율형 게임 개발 및 운영 시스템(AGDS) 구축 지시서

**본 문서는 커서(Cursor)와 아크코어(ArcCore)가 상호작용하여 스스로 코드를 수정하고, 테이블 데이터를 갱신하며, 게임의 밸런스를 자율적으로 최적화하는 '자율형 개발 시스템'의 최종 5단계 구현 가이드를 정의합니다.**

---

## 단계 1: 데이터 중심 자율 분석 엔진 (Data-Driven Insight Engine)
AABS의 감사 리포트를 단순 기록용이 아닌, 시스템이 직접 '해석'할 수 있는 구조로 전환합니다.
* **작업 지시**:
    * `npm run audit:balance`의 결과물을 JSON 형태의 `logic_input.json`으로 병렬 출력하도록 수정.
    * 아크코어가 해당 JSON을 읽어 정책(`level_band_targets.csv`)과의 수치적 격차를 백분율로 계산하는 분석 모듈 구현.
    * 분석 결과에 따라 '코드 수정이 필요한지' 또는 '테이블 값 조정이 필요한지' 판단하는 의사결정 트리 구축.

## 단계 2: 테이블 자동 패치 및 버전 관리 (Autonomous Table Patcher)
DB 및 CSV 테이블에 접근하여 필요한 값을 스스로 수정하고 즉시 게임에 반영하는 시스템을 구축합니다.
* **작업 지시**:
    * `tables/content/` 내의 정본 데이터를 보호하면서, AABS가 생성한 보정값을 오버레이하는 `dynamic_overlay.csv` 자동 생성기 구현.
    * 업데이트된 테이블 값을 앱 재시작 없이 실시간으로 `hot-swap` 할 수 있는 인덱싱 갱신 로직(`reloadTableIndices`) 개발.
    * 모든 자율 수정 내역을 Git 커밋 메시지로 자동 기록하여 개발자가 추적 가능하게 구성.

## 단계 3: 커서 연동형 코드 자동 수정 인터페이스 (Cursor-Link Code Modifier)
특정 로직의 한계가 파악되었을 때, 시스템이 스스로 코드 수정 제안서(Diff)를 작성하도록 합니다.
* **작업 지시**:
    * 성능 병목이나 로직 오류 감지 시, 해당 함수의 위치와 수정 제안 코드를 담은 `.cursorrules` 또는 `optimization_guide.md` 자동 생성.
    * 커서(Cursor)의 인덱싱 기능을 활용해 "현재 코드 구조 내에서 정책 위반을 해결할 가장 효율적인 함수 수정안"을 프롬프트 형태로 출력하는 브릿지 구축.

## 단계 4: 실시간 게임 세션 및 DB 동기화 (Live Session & DB Sync)
자율적으로 수정된 밸런싱과 배치가 실제 유저의 DB(Firestore)와 완벽히 동기화되도록 합니다.
* **작업 지시**:
    * `planetCoreRuntimeStore`의 변경 사항을 전역 서버에 브로드캐스팅하는 동기화 프로토콜 강화.
    * 유저의 진행도(`arcfire_player_v1`)와 자율 밸런싱이 충돌할 경우, 유저 데이터를 보호하면서 보정치를 적용하는 안전한 데이터 병합(Merge) 로직 구현.

## 단계 5: 자율형 루프 완성 및 가디언 모드 (Autonomous Loop & Guardian)
사람의 개입 없이 '관측-분석-수정-적용-재관측'이 무한 반복되는 루프를 완성합니다.
* **작업 지시**:
    * **자율 루프(Autonomous Loop)**: 24시간 주기로 시뮬레이션-패치-배포가 자동으로 일어나는 스케줄러(`Cron Job`) 가동.
    * **가디언 모드(Guardian Mode)**: 자율 수정된 데이터가 게임 경제를 붕괴시킬 위험(예: 인플레이션 50% 초과)이 감지되면 즉시 모든 자동화 작업을 중단하고 정본으로 롤백하는 최종 안전장치 구축.

---

### [최종 시스템 구동 시나리오]
1. **관측**: AABS가 유저 성장이 로드맵보다 느리다는 것을 JSON으로 보고함.
2. **분석**: 아크코어가 경험치 보상이 15% 부족하다고 판단함.
3. **수정**: 시스템이 `dynamic_overlay.csv`를 생성하여 경험치 배율을 1.15로 자동 수정함.
4. **적용**: 앱 내 인덱싱 엔진이 실시간으로 새 배율을 로드하여 모든 행성에 적용함.
5. **확인**: 다음 날 시뮬레이션에서 유저 성장 속도가 정상 범위로 복구되었는지 확인 후 루프 종료.

**본 5단계 파일이 완료되면, 게임은 스스로 데이터를 분석하고 코드를 제안하며 성장하는 자율 진화형 시스템으로 동작하게 됩니다.**
