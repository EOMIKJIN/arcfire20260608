## 0. 한 줄 판정

`levelup_story_merge.md`는 **챕터1 서사 재료(WHAT)** 로는 쓸 수 있다.  
**초반 3분 · 강제 튜토리얼 · 라이브 미션 id 정본(HOW)** 으로는 쓸 수 없다.

이 문서를 **맥락 잠금 정본**으로 둔다. 병합 문서의 세계관·복선은 살리고, 라이브와 충돌하는 배치·id·타임라인은 여기서 고정한다.  
이후 확장도 **같은 4계층 + 슬롯 표**로만 쌓는다.

| 묻고 | 답 |
|------|----|
| 초반 3분 기반으로 쓸 수 있나? | **부분**. 세계관 모티브(라이트홀드·은폐)는 유지. Zone1 잔해/워프게이지/30분 타임라인은 초반 3분이 아님 |
| 인게임 대화 구성 기반으로 쓸 수 있나? | **부분**. 브리핑 의도만 있음. 페이지·씬 id·게이트(1차/2차) 없음 |
| 메인 퀘스트 진행 기반으로 쓸 수 있나? | **부분**. 챕터1 Q1·Q2 줄기는 유지. 런타임 id·시작 행성은 라이브가 이김 |
| 이 방식(슬롯 표 + 유지/보강/재구성)으로 완성도를 쌓을 수 있나? | **예**. 계층을 섞지 않고, 런타임 id를 별도 칸에 두면 확장 가능 |

## 1. 네 계층 — 섞지 않는다

구현·집필은 아래를 **한 표에 합치지 않는다.** 한 줄에 계층이 둘이면 설계 위반.

| 계층 | 이름 | 플레이어가 겪는 시간 | 정본 | 라이브 |
|------|------|----------------------|------|--------|
| **L0** | 초반 3분 · 허브 강제 가이드 | 신규 첫 착륙 ~ 출발 직전 | `docs/튜토리얼_시스템.md` + 본 문서 §4 | 일부만. 강제 스텝 머신 **미착수** |
| **L1** | 튜토리얼 미션 트랙 | 출발 이후 초기 항로 | `missions.csv` `mission_001`~`005` | **실기**. HUD 최우선 |
| **L2** | 본편 메인스토리 | 세계가 열린 뒤 수락 | `MAIN_STORY_CHAPTER_SPINE.md` · `story_*` | `story_001`만 ready |
| **L3** | 캠페인 페이싱 · 서사 초안 | 수 시간 스케일 참고 | `01_10 레벨업구조.csv` · `levelup_story_merge.md` | **런타임 아님** |

보조 대화(행성 분위기): `docs/SAMPLE_SCENARIO_EARLY_ROUTE_Lv1_10.md` → `early_route_*` 씬. **manual** 트리거. L0 중 발사 금지.

```text
L0  인트로 + 스텔라 순차 실습 + 출발
L1  mission_001 「첫 비행」부터 항로·전투·무역 학습
L2  story_001 「동기 없는 살인」→ 챕터1 연퀘 (병합 문서 Q1·Q2를 여기로)
L3  밸런스/시간감 참고. missions.csv에 숫자 이식 금지
```

**금지**: L3 미션 제목·Zone1-M1을 `mission_001`로 착각 · L0에 살인사건 브리핑 · L1 클리어 조건을 L3 크레딧(30,000)으로 교체.

## 2. 잠긴 세계관 (이 값은 구현이 따라간다)

대표님 승인 없이 뒤집지 않는다. 대사 원문 교체는 별도 승인.

### 2-1. 현재 전쟁 (인트로 — 이미 실기)

`intro01` 3페이지. 덮어쓰지 않는다.

1. 크림슨 레기온이 은하 동부를 장악하고 **아크코어**를 찾아낸다.  
2. 아크코어의 힘으로 **스텔리움 연합**을 침공한다.  
3. 두 세력의 전쟁은 **지금**도 계속된다.

플레이어는 이 전쟁 한가운데 **아르카디아(`arcadia_prime`)** 에 새로 부임한 **중급 함장**이다(2026-09-15 정정 — 이전엔 "신규 파일럿"으로 잘못 기술). 불시착 잔해 미니게임은 **없다.**

> **정정 사유**: 챕터1 q03("대타 출정")에서 지휘 공백을 메울 임시 지휘관으로 플레이어가 지목되는 전개는, 플레이어가 이미 지휘 경험이 있는 중급 함장일 때 개연성이 성립한다. "막 도착한 신규 파일럿"이 갑자기 함대를 지휘하는 것은 설정 충돌이었다. 캐릭터 생성 시 직업 선택(렌 카제/미아 벨로/카일 드레이크, `prof_striker`/`scout`/`tactician`) 자체는 **화면·CSV·기본값 그대로 유지**하되, 이 세 특기는 이제 "이제 막 부임한 신입"이 아니라 **"각기 다른 방식으로 함장 보직을 수행해 온 중급 장교의 주특기"**로 해석한다.

### 2-2. 과거 상처 (챕터1 모티브 — 병합 문서에서 채택)

20년 전 변경 식민지 **라이트홀드**가 스텔리움 수뇌부에 의해 미끼로 버려지고, 47시간 만에 함락됐다.  
마지막 통신은 아이를 달래는 자장가다.  
챕터1 전체의 주제는 **「진실 은폐」** 다.

이 사건은 **현재 전쟁과 공존**한다. 인트로를 라이트홀드로 **교체하지 않는다.**  
라이트홀드 컷신(병합 §0)은 **L0 밖 · HOLD**. 챕터1 중반 회고·수락 후 플래시백 후보.

## 4. 초반 3분 — 비트 시트 (L0)

목표: 누가 말하고, 무엇을 배우고, 세계가 언제 열리는지.  
시스템 채굴 1사이클이 30초를 넘으면 **서사 3분**과 **실습 벽시계**를 분리한다. 서사는 짧게, 실습은 한 바퀴를 생략하지 않는다 (`튜토리얼_시스템.md` A0–D2).

### 4-1. 이미 돌아가는 길

```text
닉네임 확정
  → flags.introSeen · firstMissionStarted = true
  → initTutorialStory()           ← mission_001 이 이미 켜짐 (너무 이름)
  → intro01 (크림슨 / 스텔리움 / 아크코어)
  → 차원항로 (스토리 아님 · prewarm)
  → 아르카디아 착륙
  → ingame_dialog_01 스텔라 **A0만** (스캔 지시. 채굴·무역 장문 폐기)
  → 스캔 완료 전 채굴·대화·수색만 세션 잠금
  → 그 외 메뉴·QuestHUD(첫 비행) 이미 열림
```

### 4-2. 목표 길 (구현 후 · 코드는 아직 없음)

```text
닉네임 확정
  → intro01 (유지)
  → 차원항로
  → 아르카디아 착륙
  → L0 강제 가이드 A0–D2 (스텔라 1차만)
       A0 환영 → A1 스캔 → A2–A3 채굴 → A4–A5 판매
       B1 조선소(기함 확인) → C1 대화 → C2 바(열람만, 수락 잠금)
       D1 정리 → D2 출발 해금
  → 이 시점에만 initTutorialStory() / mission_001
  → 세계 오픈. story_001 수락 가능 (HUD는 L1이 위)
```

`initTutorialStory` 발화 세 곳(생성 · 인트로 완료 · 타이틀 이어하기)을 D2까지 미루는 설계는 `튜토리얼_시스템.md` §6-2. **본 스파인이 그 설계를 채택한다.**

### 4-3. L0에서 말하는 것 / 말하지 않는 것

| 말해도 됨 | 아직 금지 |
|-----------|-----------|
| 도착. 스텔리움 관문 아르카디아. 전쟁 중 | 라이트홀드 전말 · 자장가 전문 |
| 스캔 → 채굴 → 판매가 생존이다 | 동기 없는 살인 · 시신 · 복수 |
| 기함은 이미 있다. 조선소에서 본다 | 정규 전함 구매 강제 |

### 4-5. `ingame_dialog_01` — 「원문 유지 + 병기」와 「원문 분할」의 뜻

> **기록용.** v1.1에서 물은 두 안이다. v1.2에서 병기는 **철회**했고, 아래 장문은 **폐기**했다. 현재 착륙 대사는 §4-6 A0.

당시 파일에는 씬이 **하나**, 페이지가 **한 장**이었다.

- 씬 id: `ingame_dialog_01`
- 트리거: 아르카디아 착륙 1회 (`planet_landed` + `arcadia_prime` + `once`)
- 원문(한 페이지에 전부):

```text
환영합니다. [닉네임]님.
아르카디아에 무사히 도착하셨습니다.
먼저 이곳에서 채굴방법을 알려드리겠습니다.
먼저 스캔을 클릭하세요.
스캔이 완료되면 채굴 버튼이 활성화 됩니다.
채굴된 광물은 무역소에서 판매가능합니다.
행운을 빌겠습니다.
```

플레이어는 `[ 다음 ]` 한 번이면 창이 닫힌다. 그 순간 스캔·채굴·무역을 **말로만** 들었고, 버튼은 아직 안 눌렀다. 강제 가이드가 없으므로 메뉴가 열린다.

강제 튜토리얼(A0–D2)을 만들면 이 장문을 **스텝마다 짧게** 말해야 한다. 그때 CSV를 어떻게 다루느냐가 두 안이다.

#### 안 A — 원문 유지 + 신규 `hub_tut_*` 병기 (권장)

**하는 일:** `ingame_dialog_01` 행과 페이지 **글자를 한 자도 고치지 않는다.**  
옆에 **새 씬 id**를 추가한다 (`hub_tut_a0_welcome` … `hub_tut_d2_depart`).  
새 페이지 문장은 원문에서 **필요한 문장만 빌려** 짧게 쓴다. 원문 파일은 그대로 남는다.

**착륙 후 동작(구현 시):** 강제 가이드가 켜져 있으면 `ingame_dialog_01`을 **다시 틀지 않고** `hub_tut_*`만 순서대로 튼다.  
이미 `ingame_dialog_01`을 본 세이브는 `seenStorySceneIds`에 id가 남아 있어 장문이 반복되지 않는다.

| 남는 것 | 이유 |
|---------|------|
| 확정 대사 원본 | 나중에 문구를 되찾을 수 있음 |
| 기존 세이브 호환 | 본 적 있는 사람은 장문이 다시 안 뜸 |
| 기존값 규칙 | 잠긴 셀을 덮지 않음 |

**하지 않는 것:** 원문 장문과 `hub_tut_*`를 **같은 착륙에서 둘 다** 틀기. 그러면 같은 설명을 두 번 듣는다.

#### 안 B — 원문 분할 승인

**하는 일:** `ingame_dialog_01` **그 행을 고친다.**  
한 페이지를 여러 페이지로 쪼개거나, 문장을 지우거나 순서를 바꾼다.  
「먼저 스캔을 클릭하세요」가 더 이상 같은 칸에 없을 수 있다.

**왜 승인이 필요한가:** 이미 검수한 **확정 문구**를 바꾸는 것이기 때문이다. 기존값 변경 규칙.

**한계:** 페이지만 쪼개고 스텝 머신이 없으면, 플레이어는 `[ 다음 ]`만 여러 번 누르고 **메뉴는 여전히 한 번에 열린다.** 강제 가이드는 해결되지 않는다.  
이미 이 씬을 본 계정은 `once`라 **새 페이지를 보지 못한다.**

#### 한 줄로

| | 안 A 병기 | 안 B 분할 |
|--|-----------|-----------|
| `ingame_dialog_01` 글자 | **그대로** | 고침 |
| 스텝용 대사 | **새 id** | 같은 id를 쪼갬 |
| 기존 세이브 | 안전 | 새 페이지를 못 볼 수 있음 |
| 강제 클릭 | 새 씬 + 가이드 코드가 필요 | 가이드 코드는 **따로** 필요 |

**철회 (v1.2)**: 안 A 병기 보호는 이전 시스템 씨앗을 지키려던 것이다.  
대표님 후속 — 충돌하면 **교체·삭제**가 맞다. `ingame_dialog_01` 착륙 발화는 **A0 한 장**으로 이미 교체했다. A1–D2는 신규 `hub_tut_*` + 강제 가이드로 넣는다. 구 장문은 복구하지 않는다.

## 6. 이 방식으로 완성도를 쌓는 법

병합 문서의 형식은 유지한다. **칸을 두 개 더 넣는다.**

### 6-1. 확장 한 줄의 필수 칸

| 칸 | 의미 |
|----|------|
| 계층 | L0 / L1 / L2 / L3 |
| 기획 슬롯 | Zone5-M2, Q1-1-3 등 사람용 |
| 런타임 id | `mission_*` / `story_*` / `hub_tut_*` / 없음(HOLD) |
| 씬 id | `story_scenes.csv` |
| 화자 | NPC id |
| 게이트 | 1차만 / 1차→2차 |
| 변경 유형 | 유지 / 보강 / 재구성 |
| 기존값 | 건드리는 CSV 필드. 있으면 구현 전 재확인 |

런타임 id가 비면 **골격만**. 코드·CSV를 만들지 않는다.

### 6-2. 채우는 순서 (2026-09-14 개정)

**지금 코드에 넣는 것 = 본편만.**

1. **L2 Q1 잔여** — `story_001` 유지. 병합 1-3~1-5는 `story_c01_q02` 맥락(피해자 신원 공개 포함).
2. **L2 대타 출정·참사(신규)** — `story_c01_q03`·`q04`. 대표님 지시로 신설. 전멸 연출 방식은 구현 전 확정 필요.
3. **L2 Q2** — 「복수는 누가 하는 겁니까?」 → `story_c01_q05`(소환·회고·좌표) · `q06`(신호+대면, 병합 2-4~2-5 맥락).
4. **챕터1 엔딩 훅** — 상부가 다음 줄기를 연다. 챕터2는 한 줄만.

**지금 하지 않음 (추후 보강):**

- L0 강제 가이드 상태 머신 · 시설 전수 강제 · 새 튜토리얼 퀘스트 종류  
- L1 항로에 미션 종류 추가 (`mission_001`~`005`만 유지)  
- 병합 Zone 행(잔해 정찰·워프 게이지·베가 함대전·채굴 레이저·헐 강제 구매·라이선스)을 퀘스트로 구현  
- 초반에 메인 수락을 끼워 넣는 재배치

플레이 맥락은 유지한다: 3분(`intro01`+허브 생존+출발) → 기존 L1 5개 → 세계 오픈 후 본편. 그걸 **새 퀘스트로 보강하지는 않는다.**

### 6-3. 대화 작성 규칙

- 튜토리얼·메인 수락·NPC = **1차만**. 페이지 1~3. 한 페이지에 시스템 세 개를 넣지 않음.  
- NL(오퍼레이터/근원체) = 세계 오픈 후 2차. L0에서 메신저로 튜토리얼 대체 금지.  
- `early_route_*`는 행성 분위기. 메인 수락과 동시에 자동 재생하지 않음(지금은 manual). L0 landed와 경합 금지.  
- 신규 대사는 `story_scene_pages.csv`. 코드 하드코딩 금지.

### 6-4. 미션을 늘릴 때

- 학습 항로 = `mission_*` 체인. **함부로 삽입하면** HUD와 `tutorialComplete`가 밀린다. 기본은 보강 대사.  
- 본편 = `story_*` + `main_story_quests.csv` bind + `contentStatus=ready`.  
- 바 옆길 = `sandbox_*`. L0에서 수락 잠금.  
- `01_10` 전투횟수·크레딧은 `audit:balance` 참고만.
