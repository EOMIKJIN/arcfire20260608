# 아크파이어 온라인: 자동화 밸런싱 및 유저 온보딩 최적화 작업 로드맵 (Post-AABS)

**작성일**: 2026-05-12  
**참조 문서**: 문서 3 (`3.level-balance-implementation-roadmap.md`), 문서 2.2 (`2.ArcCore_AABS_Final_Spec_v2.2.md`)  
**상태**: AABS 구현 이후의 고도화 및 실서비스 전환 단계

## 1. 개요
AABS(능동형 밸런싱 시스템)를 통해 확립된 기초 밸런싱(경험치, 수익, 배치)을 바탕으로, 실제 유저 유입 시 발생할 수 있는 데이터 변동성을 제어하고 플레이어 유지율(Retention)을 극대화하기 위한 후속 작업 리스트를 정의한다.

---

## 2. 추가 작업 리스트 (Post-AABS)

### A. 유저 행동 분석 기반 정밀 보정 (User Feedback Loop)
AABS는 봇 데이터를 정본으로 삼지만, 실제 유저는 봇과 다른 '비효율적 경로'를 선택할 수 있다.
1. **유저 이탈 지점 자동 탐지**: 특정 레벨 구간이나 특정 성계에서 유저 체류 시간이 정책(`level_band_targets.csv`) 대비 1.5배 이상 길어질 경우, 해당 구간의 난이도 계수를 자동 하향한다 [cite: 2.AABS-2, 3.Roadmap-핵심격차 1].
2. **이상 경제 활동 모니터링**: 자동화된 밸런싱을 우회하는 '어뷰징 채굴'이나 '비정상 무역' 발생 시, 해당 지역의 보정 계수를 즉시 긴급 조정한다 [cite: 2.AABS-4].

### B. 자연스러운 플레이 진행 (UX/Onboarding)
유저가 시스템에 의해 '관리'받고 있다는 느낌을 주지 않으면서 자연스럽게 성장을 유도한다.
1. **미션-밸런싱 연동 엔진**: 유저의 현재 전투력이 다음 미션 권장 레벨보다 낮을 경우, 아크코어가 유저 근처에 '약한 적' 혹은 '고효율 잔해'를 배치하여 자연스러운 파밍을 유도한다 [cite: 3.Roadmap-우선순위 3, 7].
2. **동적 튜토리얼 트리거**: 봇 시뮬레이션 결과 대비 유저의 성장 속도가 현저히 늦을 경우, 스킬 학습이나 장비 교체를 권유하는 인게임 가이드 시스템을 활성화한다 [cite: 3.Roadmap-우선순위 4].

### C. 적함 배치 및 성계 생태계 고도화
1. **함대 밀도 자동 조절**: 동시 접속자 수에 따라 성계 내 NPC 함선 밀도를 조절하여, 사냥터 부족 현상이나 과도한 다굴 현상을 방지한다 [cite: 2.AABS-C].
2. **진영별 세력 균형(Faction Balance)**: 특정 진영의 플레이어가 너무 강력해질 경우, NPC 세력(과학자, 광부 길드 등)의 배치 빈도를 조절하여 세계관의 긴장감을 유지한다 [cite: 3.Roadmap-현재확인 5].

## 3. 향후 작업 목록 (Roadmap to Launch)

| 단계 | 작업 항목 | 핵심 내용 | 비고 |
| :--- | :--- | :--- | :--- |
| **Stage 1** | **실데이터 튜닝** | Sim-Bot 데이터를 실제 유저 초기 테스트 데이터로 교체 | AABS 트리거 정교화 |
| **Stage 2** | **이벤트 시스템 연동** | 특정 기간(주말 등)에 AABS 배율을 강제로 조정하는 이벤트 모드 구현 | 경제 이벤트 대응 |
| **Stage 3** | **통합 감사 대시보드** | `npm run audit:balance` 결과를 웹 대시보드로 시각화 | 운영 툴 고도화 |
| **Stage 4** | **글로벌 서버 최적화** | 지역별 유저 성향(한국/일본/동남아)에 따른 세그먼트 밸런싱 적용 | [Saved Info] 전략 참조 |

## 4. 최종 목표 점검 사항
* **자동전투**: 모든 성계 레벨(`enemyLevel`)이 유저 레벨과 유기적으로 반응하는가? [cite: 3.Roadmap-핵심격차 6]
* **배치**: 아크코어의 함장 이동 명령이 물리적으로 타당하고 자연스러운가? [cite: 1.arcfire-39]
* **경제**: 인플레이션 없이 유저가 지속적으로 장비를 교체할 동기가 부여되는가? [cite: 3.Roadmap-핵심격차 5]
