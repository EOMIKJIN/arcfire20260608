## 0. 목적
현재 아크파이어 콘텐츠를 4X(eXplore·eXpand·eXploit·eXterminate) 구조로 대조해 빠진 영역을 찾고, 필수 개발 예정 콘텐츠인 **외교**를 시스템 수준으로 구체화한다.

## 1. 현황 (프로젝트 문서 기준)
- **[문서]** 함대전(45초 숏폼 전투), 공성/수성, 무역·채굴, 시설 3종(무역소·조선소·방위위성 각 10레벨), 행성 5대 속성 R&D 15단계, TDI, 정책 선택·비콘, 일 1회 배치(AABS).
- **[문서]** 세계관 문서: "결혼을 통한 가문 동맹, 법령 투표, 자녀 승계, 국가 건국" 언급. 메모리 설계서 콘텐츠 목록: "가문 등급, 동료 영입, 결혼/가문, 국가 건국, 외교 행동".
- **[문서]** 외교 관련 구현 변수는 TDI 설계서의 "외교적 영향력 = NPC 거래 우호적 가격 책정 확률 증폭" 1건뿐.
- **미확인**: 외교를 독립 시스템으로 정의한 상세 기획서/CSV는 이번 검색에서 확인되지 않음 → 외교는 사실상 미정의 영역으로 간주(기존 문서가 따로 있다면 그쪽을 정본으로 한다).
- **[문서] 헌법 제약**: 싱글플레이, 실유저 간 상호작용 없음, AI가 동맹/적을 시뮬레이션, 시장 탄력 없음(일 1회 배치 내 확정 변동).

## 3. 외교 시스템 설계안 [제안]

### 3.1 관계 모델
- 상대(팩션 4개 + 개별 NPC 세력)별 **호감도**와 **신뢰도**를 분리한다. 호감이 높아도 약속을 어기면 신뢰가 하락한다.
- 상태 단계 예: 적대 → 냉각 → 중립 → 우호 → 동맹.

### 3.2 조약 종류
| 조약 | 효과 방향 (수치는 미정) |
|---|---|
| 불가침 | 상호 공격 금지, 위반 시 신뢰도 큰 하락 |
| 통상 협정 | 무역소 수수료 인하·항로 개방 (기존 시설/무역 CSV와 연동) |
| 군사 동맹 | 공동 방어, 지원 함대 요청 |
| 조공·보호령 | 종속 관계, 정기 상납 |
| 휴전·항복 | 전쟁 종결, 점령지 처리 |
| 가문 동맹(결혼) | 기존 가문 시스템을 외교 카드로 연결 |

### 3.3 협상 구조
- 제안 → 수락/거절/역제안 → 최후통첩 순서. 수락 확률은 관계 점수·전력비·TDI 외교적 영향력으로 산출.
- 선전포고에는 명분이 필요하고, 명분 없는 개전은 타 세력 평판 하락.
- 동맹 요청 거절/수락이 신뢰도와 제3 세력 반응에 연쇄 반영.

### 3.4 헌법 정합성
- 외교 상대는 전부 AI 세력이므로 싱글플레이 헌법과 충돌하지 않는다.
- 외교 상태 변화는 **일 1회 배치(AABS)** 안에서 확정하는 방식을 기본으로 하고, 실시간 변동이 필요하면 헌법 §10 계약과의 충돌 여부를 먼저 검토한다.
- AABS의 1회 5%/누적 15% 캡 원칙과 외교 보정 배율의 네임스페이스 분리가 필요(정책 배율 분리 제안과 동일 방식).

### 3.5 아크코어 / LLM NPC 연동 (차별점)
- 일반 4X의 외교는 메뉴에서 수치를 고르는 방식이 중심이다 **[일반]**. 아크파이어는 사절·함장 NPC와 **대화로 협상**하고, 결과는 tool use로 **구조화된 조약 데이터**로 저장한다(NPC 데이터 학습처리 문서 §4.2 원칙).
- 반복 명령은 템플릿, 서사적 협상만 선택적 LLM 호출(토큰 비용 통제).
- 협상 대화 로그의 요약은 NPC×유저 관계 프로필에 누적되어 다음 협상에 반영.

### 3.6 사업 관점
- 외교 대화는 핵심 BM(AI Companion Pass / AI 스토리 메이커)과 연결된다. 단, 외교 결과가 승패를 사는 구조가 되면 Pay-for-Depth 원칙에 어긋나므로 과금 연동 범위는 별도 검토.

## 4. 우선순위 제안 [제안]
1. **P1** 외교 관계 모델 + 기본 조약 3종(불가침·통상·휴전) + 데이터 테이블(Table-First)
2. **P1** 선전포고/명분 + 종전 협상
3. **P2** 군사 동맹·가문 동맹 연동
4. **P2** LLM 협상 대화 + 조약 구조화 추출
5. **P3** 조공/보호령, 정보전, 은하 위기 이벤트, 국가 단위 기술 트리
