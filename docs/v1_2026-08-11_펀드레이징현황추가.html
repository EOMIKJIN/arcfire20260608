01 · TARGET MARKET

타겟 시장

SF·전략 장르를 중심으로 틈새 수요가 급격히 확대되고 있습니다.

핵심 시장 트렌드 — 왜 지금인가?

📉
헤비 MMORPG 이탈
국내 MMORPG 비중 2020년 78.8% → 2024년 56.2%로 급락. 무거운 과금·긴 플레이타임에 지친 유저들이 대거 이탈 중.
📈
라이트 장르 급성장
방치형 RPG 2020년 1.7% → 2024년 16%로 급성장. '버섯커 키우기'는 국내 매출 3위 달성. 캐주얼·전략 장르도 동반 급성장.
🌏
아시아 태평양 주도
APAC이 글로벌 MMORPG 수익 61% 점유. 한국·일본은 Tier-1 시장으로 ARPU 최상위, 장기 리텐션 우수.
🚀
SF 전함 로망의 공백
EVE Echoes 진입장벽 과다, Star Trek FC는 IP 종속·과금 압박 과다. '가볍게 즐기는 SF 전함 수집·전략'을 충족하는 제품 부재.

집중 타겟 시장

  • 핵심 시장:  SF 세계관 + 전함 수집·전투 기반의 Lite-MO 게이머 세그먼트
  • 지역 우선순위:  Tier-1 — 대한민국·일본 / Tier-2 — 동남아시아 (볼륨 확장)
  • 플랫폼:  모바일 전용 (Android 우선, iOS 병행) — 국내 수익의 75%가 Google Play 발생
  • 장르 포지셔닝:  전략 시뮬레이션(11.6%) × SF MMORPG(22%) 교차점 — 공백 니치 공략

시장이 확인한 Pain Point

기존 SF·전략 모바일 게임 유저들은 구조적인 불편을 경험하고 있습니다.

⚔️ 강제 경쟁 스트레스실시간 PVP·길드전 강요, 유저 간 약탈 문화"게임이 노동" 인식, 부정 리뷰 급증
📱 기기 성능 의존고사양 3D 렌더링 중심, 발열·렉 빈발중저가 스마트폰 보급 시장에서 이탈 원인 1위

03 · SOLUTION

SF 로망 × 경량 MO × 전략적 깊이

무거운 MMORPG 없이도 깊이 있는 수집·성장·전투 경험을 하나의 패키지로 제공합니다.

01
서버리스 MO 아키텍처
Firestore 기반 상태 관리 + 이벤트 드리븐 설계. 전용 서버 0원 구조.
서버 비용·렉 문제 근본 해소
02
비동기 멀티플레이
5~10초 스냅샷 방식 타 유저 렌더링. 실시간 소켓 동기화 미사용.
경쟁 스트레스 0, 공간 공유의 즐거움 유지
03
Skia 하이브리드 렌더링
React Native Skia 기반 경량 GPU 렌더링. 메모리 최적화 자체 검증.
중저가 기기 발열·렉 문제 해소
04
72단계 무기 시스템
D&D 3.5e 기반 설계. 4~8단계 단위 점진적 구현 + AI 단위테스트.
장기 리텐션·전략 깊이 확보

04 · TARGET CUSTOMER

타겟 고객

핵심 페르소나 — 직장인 SF 게이머 (30~50대 남성)

  • 출퇴근·점심시간 등 짧은 세션(5~15분)에 게임을 즐기고 싶다
  • 우주·SF 세계관에 대한 강한 로망 — 전함 수집과 성장 그 자체가 즐거움
  • 실시간 경쟁 없이 나만의 속도로 성장하는 경험을 원한다
  • 저사양 스마트폰으로도 부드럽게 구동되는 쾌적한 환경 필요
  • 복잡한 튜토리얼 없이 자동 전투 + 전략적 배치에 집중하고 싶다

고객 세분화

구분지역특성전략적 가치
Tier-1 (최우선)대한민국 · 일본ARPU 최상위, 전략·수집 장르 고과금 문화초기 코어 유저 확보 / 브랜드 구축
Tier-2 (확장)동남아 (태국·인니·필리핀)모바일 침투율 급성장, 중저가폰 점유 높음볼륨 확대·바이럴·Skia 최적화 극대

확보 채널 전략

  • Performance 마케팅:  Google UAC 기반 Tier-1(한국·일본) 집중, AI 자동 최적화
  • 수집·성장 후킹:  D&D 3.5e 72단계 무기 시스템 — 짧은 세션이지만 매일 돌아오는 루프
  • Web3 확장 (중장기):  TON 네트워크·JUS 토큰 통합으로 블록체인 게이머 세그먼트 선점
  • 바이럴 기반:  전함 커스텀·배치 결과물의 SNS 공유 유도 — 시각적 자랑 요소 내재화

07 · INVESTOR APPEAL

핵심 투자자 어필 포인트

Arcfire Project이 단순한 게임을 넘어 구조적 시장 기회를 포착하는 투자 대상인 이유.

POINT 01
검증된 시장 타이밍
리니지 M·W 매출 급락(▼16%~36%)과 방치형 RPG 폭발적 성장(1.7%→16%)이 "헤비 MMORPG → 라이트 전략" 구조적 전환을 명확히 증명했습니다.
  • EVE Echoes 한국 유료결제 중단(2024.02) — Tier-1 시장에 직접 공백 발생
  • 방치형·전략 장르 수요 급증 시점과 출시 타이밍 완벽 일치
POINT 02
기술적 해자 — 서버비용 0원 구조
Firestore 서버리스 아키텍처와 비동기 MO 설계로 전용 서버 운영 비용 제로를 실현. React Native Skia 경량 렌더링은 이탈률을 구조적으로 낮춥니다.
  • 서버 비용 절감 → 투자금의 더 높은 비중을 마케팅·콘텐츠에 집중 가능
  • 72단계 무기 시스템 → 짧은 세션에도 매일 돌아오는 루프 (장기 리텐션)
POINT 03
공백 니치 선점 — 경쟁사 미점유
"조작 난이도 낮음 × 경쟁 스트레스 없음" 포지션은 현재 어떤 경쟁사도 점유하지 않은 블루오션입니다.
  • 전략 시뮬레이션(11.6%) × SF MMORPG(22%) 교차점 — 충분한 TAM
  • 독자 IP 보유 → IP 라이선스 리스크 없음, 세계관 확장 자유도 확보
POINT 04
명확한 수익 모델 — MRR 구조
배틀패스 기반 수익 모델로 72단계 성장 경로 + 짧은 세션 완결 구조가 결합되어 유저가 꾸준히 과금하는 선순환 구조를 만듭니다.
  • 배틀패스 BM → 월 반복 수익(MRR) — 예측 가능한 현금흐름
  • SNS 공유 유도 내재화 → CAC(유저 획득 비용) 절감 구조
POINT 05
검증된 팀 실행력 — 핵심 마일스톤 50% 달성
채널 할당 로직·스냅샷 렌더링 프로토타입·72단계 무기 밸런싱·Firestore 연동을 완료하였으며, 현재 베타 테스트 및 Tier-1 런치 준비 단계를 진행 중입니다. 절반의 검증이 완료된 지금, 추진력을 갖춘 팀에 합류할 최적의 시점입니다.
  • 서버리스 부하 테스트 완료 → 기술 리스크 해소
  • 투자금 사용처: Google UAC Tier-1 마케팅 집중 → 초기 코어 유저 확보 → 시리즈 A 유치
  • Web3 (TON·JUS 토큰) 통합 — 중장기 블록체인 게이머 세그먼트 확장 옵션
