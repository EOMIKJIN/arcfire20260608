## 0. 한 줄

**지금 보이는 은하 지도 = 안개가 전부 걷힌 끝 모습.**  
신규는 그 지도 위에 흑·회색 포그를 덮고, **아르카디아 + 항로 1홉 별만** 보여 준다.  
그 별을 눌러 도착하면 **이름과 실제 노드 형체**가 열리고, 거기서 다시 연결된 별이 프론티어로 확장된다.

존 로딩(Z1)은 메모리 페이로드다. 이 기능의 축이 아니다.

## 1. 일반 포그 · 스텔라리스 · 아크파이어

### 1-1. 일반 전략 포그 (AoE / Civ)

| 층 | 의미 |
|----|------|
| Unexplored | 한 번도 안 봄. 검정. 지형·유닛 없음 |
| Explored | 가 본 적 있음. 지형은 기억. 유닛은 없음 |
| Visible | 지금 시야. 실시간 |

### 1-2. 스텔라리스 은하 지도

홈 성계만 밝다. 나머지는 안개. 센서·항로 탐지가 **1홉(또는 N홉)** 끝의 별을 보여 준다.

| 스텔라리스 | 은하 지도에서 |
|------------|----------------|
| Shrouded | 포그. 성계 없음(또는 윤곽만) |
| Hyperlane detected | 회색 항로 + **이름 없는 별**. 눌러 탐사 가능 |
| Explored (방문·센서) | **이름** · 성계 형체 |
| Surveyed | 자원·이상. 과학선. **아크파이어에는 없음** |
| Sensor range | 함대 실시간. **아크파이어에는 없음** |
| Empire intel | 외교 정보. **이 계획 밖** |

시작 직후: 홈은 차트. 홈에서 나가는 항로 끝 별만 보임. 들어가면 이름이 뜨고, 그 성계의 다음 항로가 열린다.

### 1-3. 아크파이어 1안 (스텔라리스를 모바일 한 줄로)

과학선·센서 테크·함대 시야는 없다. **도착 = 탐사 + 측량.** 센서 홉 = **항상 1.**

| 층 | 정의 | 화면 |
|----|------|------|
| **차트됨** | `visited` ∪ 현재 성계 | 실제 노드 형체 + 이름 + 패널 |
| **프론티어** | 차트됨의 **항로 1홉** − 차트됨 | 별 비주얼만. 이름·형체·점유 없음. **탭 → 이동** |
| **차폐** | 그 밖 | 흑·회색 포그. 노드·라벨·항로·점유색 없음 |

## 2. 시작 상태 (정본 그래프)

월드맵 이동 그래프는 `GALAXY_SYSTEMS` (`galaxySystems100.generated.ts`)다.  
아르카디아 연결 **3개** — 대표님께서 말한 「연결된 3개의 별」과 같다.

| id | 종류 |
|----|------|
| `solar_port` | 코어 · 솔라 항구 |
| `vega_outpost` | 코어 · 베가 전초기지 |
| `synth_073` | 레거시 미개척 |

신규 `visited = [arcadia]`, 현재 = 아르카디아.

- 차트됨: 아르카디아 (이름·형체)
- 프론티어: 위 3개 (별만)
- 나머지 가시 113·별빛: 포그 아래

개수를 3으로 하드코딩하지 않는다. `connections` 길이를 따른다.

`listAdjacentSystemIds`(분쟁/보급)는 CSV 21코어만 본다. **포그·이동은 월드맵과 같은 `system.connections`만** 쓴다.

## 3. 규칙

```text
charted  = visitedSystemIds ∪ { currentSystemId }
frontier = (∪ neighbors(charted) − charted) ∩ visibleSystemsList
shrouded = visibleSystemsList − charted − frontier
```

`neighbors` 정본은 `GALAXY_SYSTEMS.connections`.  
가시 113 밖 이웃은 프론티어로 **그리지 않는다** (bbox·카메라 113 고정 · 700 구조 누설 금지).  
일일 `unlockSystem`로 목록에 들어온 뒤에야, 그때 1홉이면 프론티어.

| 행동 | 결과 |
|------|------|
| 프론티어 탭 | 선택·이동만. 이름 공개 없음 |
| 도착 `markVisited` | 그 성계 → 차트됨. 그 연결분 → 새 프론티어 |
| 차트됨 탭 | 지금과 같은 정보 |
| 차폐 탭 | 없음 (히트 없음) |
| 한 번 차트 | 유지. 초기화 시 `visited`와 함께 리셋 |

기존 세이브: 이미 방문한 성계는 걷힌 채로 남는다. 많이 돌아다닌 계정은 지금 지도에 가깝다.

## 4. 화면

지금 지도의 노드·라벨·보로노이 = **포그가 걷힌 뒤**의 모습. 그 에셋을 차트됨에 그대로 쓴다.

| 레이어 | 차폐 | 프론티어 | 차트됨 |
|--------|------|----------|--------|
| 흑·회색 포그 (SVG Rect 1, 맵 전면) | 덮임 | 별이 포그 **위** | 노드가 포그 **위** |
| 노드 형체 | 없음 | 없음 | 현행 노드 |
| 별 비주얼 | 없음 | 있음 | — |
| 이름 | 없음 | 없음 | 있음 |
| 항로 | 없음 | 차트↔프론티어만 옅은 선 | 차트↔차트 현행 |
| 보로노이·점유 | 없음 | 없음 | 차트 사이트만 |
| 패널 | — | 「미탐사」 또는 이동만 | 현행 |
| 미발견 별빛 | **그리지 않음** (구조 누설 금지) | 선택: 근처만 | 현행 가능 |

카메라·bbox는 **지금 가시 113 좌표계를 유지**한다. 포그가 덮을 은하 프레임이 필요하다. 시작 때 아르카디아 쪽으로 맞추는 줌은 이 계획에 넣지 않는다.

포그는 Skia Canvas가 아니다. SVG Rect 1 + 차트/프론티어를 위에 그린다. 구멍 마스크·프레임당 Path 금지.

## 6. 데이터

기록은 `worldStore.visitedSystemIds` · `markVisited`만. persist·클라우드·purge 기존.

파생 함수 (순수, 이동 완료 시에만):

```text
resolveGalaxyMapFogView({
  visitedSystemIds, currentSystemId, getConnections
}) → { chartedIds, frontierIds }
```

렌더는 `charted ∪ frontier`만. `visibleSystemsList`는 bbox·존 로드 입력으로 둘 수 있으나 **차폐 노드는 그리지 않는다.**

## 8. 개발 단계

```text
S0  본 문서
S1  resolveGalaxyMapFogView + 테스트
    시작: charted={arcadia}, frontier={solar_port,vega_outpost,synth_073}

S4  포그 Rect (흑·회) · 차트/프론티어 z-above
S5  항로: 차트–차트 / 차트–프론티어만
S6  탭·이동·패널 게이트 (차폐 히트 없음)
S7  별빛: 차폐 칸 비표시
```

## 11. 재점검 (2026-08-22 · 김팀장)

줌 마무리 후 코드 대조. **축은 유지. 아래만 보정·착수 조건.**

| 항목 | 판정 |
|------|------|
| 구현 파일 | `resolveGalaxyMapFogView` **없음**. 렌더는 가시 113 전부 공개 |
| 아르카디아 연결 | `solar_port` · `vega_outpost` · `synth_073` — 그래프 정본과 일치 |
| persist | `visitedSystemIds` + `markVisited`만. 신규 시드 `['arcadia']`. 클라우드·purge 기존 |
| 차트 갱신 시점 | `moveToSystem` **커밋**(무조우 연출 전). `currentSystemId`가 차트에 들어가므로 이름 공개는 출발 커밋과 같음. 연출 종료를 기다리지 않음(2026-08-02 이동 커밋 계약) |

| 솔라 1홉 | `solar_port` → `new_eden` · `arcadia` · `minerva`. S1 예시는 맞음 |
| 줌 | 포그 Rect는 1× SVG 안. 카메라 transform이 같이 확대. 핀치·배율 사다리와 **무관** |

| 이름 충돌 | `worldExpansionFrontier`(일일 개방) ≠ 포그 프론티어. 코드는 `fogFrontier` |
