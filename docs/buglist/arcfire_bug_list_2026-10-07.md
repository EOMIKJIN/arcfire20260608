# 아크파이어 플레이테스트 버그 및 수정사항 (2026-10-07)

## A. 최우선

### 1. 미네르바 딥: 드록 한 전투 종료 후 진행 불가 (반복 재현)
- **현상:** 성계 진입 시 드록 한(NPC)과 전투 발생 → 전투 완료 후 내 전함만 남은 채 허브 화면이 멈춤 → 출발 후 다시 진입하면 같은 전투가 반복됨
- **참고:** 미네르바 딥에서는 적함 파괴 연출이 정상적으로 보임
- **확인 필요:** 퀘스트 전투인지 일반 조우 전투인지 불명확. 전투 결과 처리(승리 판정 → 퀘스트 플래그 저장 → 허브 복귀)를 함께 점검해야 함

## B. 안정성

### 2. 아르카디아 귀환 후 재탑승 시 크래시
- **재현 경로:** 약 1시간 플레이 → 먼 외곽 성계로 이동 중 전투 패배 → 아르카디아 귀환 → 재탑승 → 크래시
- **발생 시각:** 약 5:00
- **확인 필요:** "5:00"이 실제 시각인지, 재탑승 후 경과 시간인지 표기 필요

## C. 무기 수치 / 발사 수

### 3. 유도미사일 3연발이 설정보다 많이 발사됨
- **기대:** 3발
- **실제:** 4발 발사 후 1발 추가 발사
- **확인 필요:** 총 4발인지 5발인지 명확히 할 것

### 4. 노바미사일이 1발 설정인데 2발 발사됨

### 5. 유도미사일 2연발의 데미지가 3연발보다 약함
- 의도된 밸런스인지 확인 필요
- 3번(3연발 초과 발사)이 원인일 수 있으므로 3번 수정 후 재비교

## D. 전투 연출 / 성능

### 6. 허브 전투 끊김 현상 지속

### 7. 아르카디아 해적 소탕 전투: 적 파괴 연출 이상
- 파괴 연출이 기준 시간·타이밍보다 너무 빨리 사라지거나, 아예 출력되지 않음
- **정상 비교군:** 헬리오스 이동 중 전투, 미네르바 딥 전투는 연출 정상 → 허브 전투 경로에서만 발생하는 문제로 보임

## E. 이동 중 전투 / 경로

### 8. 다중 홉 이동 시 경로상 이동 중 전투가 발생하지 않음
- **현상:** 아르카디아에서 아주 먼 지역에서 오로라 관측국부터 4홉 이동했으나 이동 중 전투 미발생. 착륙 후 재출발하면 발생. 1칸씩 이동하면 정상 발생
- **기대:** 최종 목적지 도착 전이라도 경로상 각 성계에서 전투 판정이 일어나야 함. 전투에 걸리면 그 자리에서 이동을 멈추고 이동 중 전투로 전환

### 9. 크림슨 레기온 지역 처리 추가
- 지역 진입 시 **위험지역 경고** 표시
- 목적지 경로가 크림슨 레기온 성계를 지날 경우 **이동 금지** 또는 **강력한 적 전투 발생**
- **확인 필요:** 둘 중 어느 쪽으로 할지 기획 결정

## F. 개척 / 스텔리움 편입

### 10. 헬리오스: 편입과 개척 절차가 중복 진행됨
- **진행 과정:** 중립지역 헬리오스에 방위위성 + 군사령부 동시 설치 → 위성 완료 → 스텔리움 즉시 편입 → 이후 개척선이 또 도착 → 푸른색 개척 효과 표시 중
- **기대:**
  - 개척 과정이 필요한 곳이면 개척 완료 전까지 스텔리움 편입 버튼이 표시되지 않아야 함
  - 이미 개척이 완료된 곳이면 개척선이 출발·도착하지 않아야 함
- **비교 테스트:**
  - 오로라 관측국(중립): 정상 절차 진행 → 개척선 출발 → 아직 중립
  - 드라코 성운(이미 스텔리움): 위성·군사령부 설치 시작 → **결과 미기재, 확인 필요**
- **추정(코드 확인 전, 미확정):** 군사령부 동시 설치 시 편입 조건 체크가 개척 상태를 건너뛰는 것으로 보임

## G. UI

### 11. 허브 NPC 인포 대사창에서 "다음" 클릭 시 전체 깜박임
