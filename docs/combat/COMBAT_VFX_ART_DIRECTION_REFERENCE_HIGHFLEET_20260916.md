## 0. 참고 영상 개요

**HighFleet** (Konstantin Koshutin / MicroProse, 2022) — 2차대전~냉전 사이 소련권 대체역사 세계관의 비행전함 슈팅+전략 게임. 참고 영상은 `Sevastopol` 기함이 `Veteran Gunner`(재장전 +20%) 특성으로 적 "SG" 함대에 근접 포격을 퍼붓는 실시간 전투 장면이다.

영상 자체를 도구로 프레임 단위 열람은 못했으나(YouTube 스트림 직접 접근 불가), **대표님이 실제 전투 장면 스크린샷 1장을 첨부**해주셔서 아래 §2는 해당 이미지를 직접 분석한 실측 내용이다. 나머지(§1의 일반 아트 디렉션 서술)는 HighFleet의 공식적으로 잘 알려진 특징(디젤펑크 소련 산업미, 실루엣 위주 함선 디자인, 아날로그 CRT UI)에 근거한다.

## 1. 핵심 아트 디렉션 키워드

| 키워드 | HighFleet에서 | 아크파이어 적용 방향 |
|---|---|---|
| **하이퍼-리얼리즘 실루엣** | 함선이 실제 군용기·군함처럼 각지고 투박함. 화려함보다 「존재감」 | 아크파이어 함선은 이미 SF 실루엣이지만, 무기 발사 시 함체 형태가 이펙트에 묻히지 않도록 이펙트는 함체 **외곽선 밖**에서만 전개 |
| **저채도 배경 + 고채도 이펙트 대비** | 전장 배경(연무·구름·밤하늘)은 무채색~저채도, 포격/화염만 원색 | 아크파이어 궤도 배경은 어둡게 유지하고, 무기 tint/glow(`weapon_special_fx_policy.csv`)만 채도를 확실히 끌어올려 **배경 vs 이펙트 대비**를 지금보다 선명히 |
| **예광탄(트레이서) 궤적** | 연사 화기가 점선이 아니라 「이어지는 빛의 선」으로 보임 — 탄속·연사력이 시각적으로 체감됨 | 이미 `buildLaserBolt`(core+glow 2중 라인)가 이 구조. 연사 무기는 **glowWidthMul을 발사 간격에 반비례**시켜 "난사감"을 강화하는 CSV 축 검토 가치 |
| **묵직한 화염/폭발 (섬광 → 잔광)** | 명중 시 순간 섬광이 크고, 이후 붉은 화염/검은 연기가 잔류 | 아크파이어 명중 이펙트(`markMs`)는 현재 즉시 사라지는 톤 색상 위주. **1단계 화이트/옐로 섬광(≤120ms) → 2단계 주황 잔광(현재 markMs 유지)**의 2단 구조 제안 |
| **손상 누적의 시각화** | 함선이 맞을수록 외장이 그을리고 파편이 튐 (편집증적 리얼리즘) | 아크파이어는 HP만 게이지로 표시. `statusTintUntilMs`를 활용해 **저HP 함선에 지속적 저채도 그을음 틴트**를 얹는 저비용(Skia 루프 무할당) 옵션 검토 가능 |
| **아날로그 CRT/스코프 UI** | 조준경·레이더가 초록/호박색 인광 스캔라인 느낌 | 아크파이어 UI는 이미 SF 홀로그램 톤이라 직접 이식은 부적합. 다만 **저HP 경고·EMP류 효과의 화면 노이즈 연출**(과한 애니메이션 금지, 정적 틴트 오버레이 수준)은 참고 가치 |
| **근접 포격의 "밀도감"** (영상 핵심 장면) | 여러 포문이 동시에 짧은 간격으로 발사 → 화면이 예광탄으로 가득 참 | 아크파이어 다연장(로켓 10~12연사 등, `weapon_special_fx_policy.csv`)은 이미 연사 패턴 보유. **발사 간격을 미세하게 지터링**해 기계적으로 일정한 리듬 대신 "쏟아붓는" 느낌 강화 검토 |
| **조명 톤 — 황혼/야간** | 전투 장면 다수가 석양~야간, 함체 실루엣과 포화가 유일한 광원처럼 보임 | 아크파이어 궤도 전투 배경이 이미 어두운 편이면 유지, 밝은 배경일 경우 **전투 진입 시 배경 채도/명도를 살짝 낮춰 이펙트 대비를 세우는** 연출 고려 |

## 2. 실측 스크린샷 분석 — 근접 포격전 장면 (대표님 첨부)

함대 두 편이 좌우로 교전 중인 순간. 좌측에 거대 폭발, 우측 함선은 함미가 화염에 휩싸임, 중앙 전체에 예광탄 크로스파이어, 하단에 조준 UI.

### 2-1. 실측 색상 (HEX 추정치)

| 요소 | 색상 | HEX(추정) | 비고 |
|---|---|---|---|
| 하늘/배경 | 차갑고 탁한 슬레이트 블루그레이 | `#5B6672` ~ `#7A8590` | 채도 매우 낮음, 안개 낀 듯한 단일톤. 거리 원근에 따라 더 밝아짐(대기원근) |
| 대폭발 코어 | 거의 백색에 가까운 옅은 황색 | `#FFF7E0` | 화면에서 가장 밝은 지점 — 유일한 순백색 영역 |
| 대폭발 중간광 | 밝은 주황 | `#FDBA74` | 코어를 감싸는 halo |
| 대폭발 외곽광 | 진한 주황 | `#F97316` | halo 바깥, 배경과 섞이는 경계 |

| 조준선(타겟 tether) | 옅은 백색, 반투명 | `#F5F5F4` (낮은 opacity) | 조준 원 → 대상 함선을 잇는 가는 직선 1개 |

### 2-2. 구도·연출 관찰

1. **광원이 이펙트 자체뿐** — 배경 하늘에는 광원이 없고, 폭발/화염이 장면의 유일한 빛. 함선 실루엣도 이 불빛에 반사되는 정도로만 형태가 드러남.
2. **트레이서는 "선"이지 "점"이 아니다** — 각 탄환이 3~8px 길이의 가는 대시로 그려져 탄속감을 만든다. 밀도가 높은 구간(양 함대 사이 중앙)에 예광탄이 집중되어 "탄막" 인상을 준다.
3. **대기원근(aerial perspective)** — 가까운 함선(우측, 화염 함선)은 크고 진하게, 먼 함선(중앙~좌측)은 작고 배경 회색에 더 섞여 보임. 색 대비도 거리에 따라 약해짐.
4. **파편은 방사형 낙하** — 폭발 지점에서 사방으로 퍼지되 약간의 포물선(중력) 궤적. 실루엣만 처리되어 렌더 비용이 낮아 보임(디테일 없는 다각형/점 수준).
5. **UI는 최소·단색·진단화면 톤** — 화려한 HUD 프레임 없이 숫자·원·선 3요소만. 색상은 라임 계열 단일색으로 통일 — 배경이 차갑고 이펙트가 따뜻하니 UI는 그 중간(형광 연두)에 위치해 항상 눈에 띔.

## 3. 색감 팔레트 적용 제안

HighFleet은 "탁한 냉색 배경 + 신호탄 난색 이펙트 + 형광 연두 UI"의 3단 구조다(§2 실측 확인). 아크파이어는 이미 SF 네온 톤(보라·시안 계열)을 쓰고 있으므로 **팔레트를 통째로 바꾸는 것이 아니라 이 "냉색 배경 vs 난색 이펙트 vs 단색 UI" 대비 구조**만 차용하는 것을 제안한다.

| 용도 | HighFleet 실측 | 아크파이어 현재(CSV 예시) | 제안 |
|---|---|---|---|
| 일반 레이저/탄막 | 트레이서 `#FB7185`/`#F97316`, 가장 뜨거운 궤적만 `#FEF3C7` | 무기별 상이 | 기본 등급 무기는 **경고성 난색(주황·적색 계열)** 유지 — 이미 `#F97316`류 사용 중, 방향 적합. 다연장탄은 **가장 최근 발사분만 살짝 밝게**(연속발사 중 마지막 탄 강조)하면 §2-2 "탄속감" 재현 가능 |
| 고급/특수 무기 | (등급차 없음) | 보라(`#A78BFA`, `#7C3AED`) · 시안 계열 | 유지 권장 — 난색 일반탄 사이에서 보라/시안이 "이질적 위협"으로 더 잘 도드라짐 |
| 명중/폭발 섬광 | 코어 `#FFF7E0` → 중간 `#FDBA74` → 외곽 `#F97316` 3단 그라디언트 | 톤 컬러 즉시 단색 표시 | **명중 최초 프레임만 `#FFF7E0`에 가깝게 밝히고 1~2 프레임 내 무기 고유색으로 복귀**(신규 alloc 없이 opacity/색상 보간만) — §2-1 실측 그라디언트 재현 |
| 함미 화염(지속 피해) | `#FDE047`→`#F59E0B`→`#C2410C` | 없음 | 저HP·화재 상태 표현 시 **statusTintHex를 이 3색 중 하나로 시간에 따라 전이**시키는 방식 검토(신규 Paint 없이 tint 색상만 보간) |
| 연기·파편 | `#1C1917`~`#3F3F46`, 무디테일 실루엣 | 없음/약함 | 대형 함선 파괴 연출 시 **디테일 없는 어두운 파편 실루엣**(신규 폴리곤 최소화, 이미 있는 파티클 풀 재사용) 검토 |
| 배경(궤도/우주) | `#5B6672`~`#7A8590`, 무채색·안개톤 | 우주 배경(현재 톤 유지) | 전투 중 **배경 채도를 낮추고 살짝 밝은 회청색 쪽으로**(STAGE3 진입 시 1회 적용) — 이펙트 대비 강화 |
| UI 강조색(HP·조준) | 라임그린 `#BEF264`~`#D9F99D` 단일 계열 | 아크파이어 SF 홀로그램 톤(다색) | 직접 이식은 부적합(브랜드 톤 상이). 다만 **"위협 상황 한정 단색 강조"라는 원칙**(급박한 정보일수록 색 종류를 줄인다)은 참고 가치 |

## 4. 아크파이어 기존 시스템과의 연결점 (구현 시 참고)

실제 반영 시 아래 기존 파일/구조를 통해서만 조정한다 — **신규 렌더 파이프라인 금지, 기존 Table-First + Skia 구조 재사용**.

| 항목 | 정본 |
|---|---|
| 무기별 tint/glow 색상 | `tables/balance/weapon_special_fx_policy.csv` (`tintHex`/`glowHex`) |
| 레이저 빔 렌더 (core+glow 2중선) | `src/components/planet/PlanetEdenRaidOrbitSkiaCombat.tsx` `buildLaserBolt()` (~308행) · draw 호출 (~912~925행) |
| 함체 상태 틴트(피격/버프 등) | `Agent.statusTintUntilMs` / `statusTintHex` — 이미 존재하는 임시-상태 필드 패턴, 저HP 그을음 연출에 재사용 가능 |
| 명중/AoE 마크 지속시간 | `markMs` 컬럼 (CSV) |
| 특수 상태(슬로우·EMP 등) | `slowMul/slowMs`, `empMs`, `interceptNearby`, `stripShield` 등 기존 컬럼 |

**PSS/메모리 원칙(변경 없음, CLAUDE.md 1순위)**: 위 제안 중 어느 것도 Skia 프레임 루프 내 `Make()`/`Paint()` 신규 생성이나 Path `.map()`을 요구하지 않는다. 모두 (a) CSV 색상값 조정, (b) 기존 `statusTintUntilMs` 패턴 재사용, (c) STAGE 진입 시 1회성 배경 밝기 조정 수준으로 한정해야 실제 착수 시 리스크가 없다.

## 5. 이번 영상에서 가져올 수 있는 "가장 임팩트 있는" 1가지

영상 제목과 실측 스크린샷(§2)이 공통으로 가리키는 것은 **"베테랑 거너가 짧은 시간에 여러 포문을 몰아쏘는 근접 연사의 밀도감 + 그 탄막이 선분(트레이서)으로 시각화되는 것"**이다. 아크파이어에도 이미 다연장/연사 무기(로켓 10~12연사 등)와 `buildLaserBolt`의 core+glow 2중선 구조가 있으므로, 그래픽 우선순위를 하나만 고른다면:

> **연사 무기의 발사 리듬에 미세한 불규칙성(지터)을 주고, 크로스파이어 밀도가 높은 구간에서는 가장 최근 발사된 탄만 살짝 밝게(§2-1의 `#FEF3C7`급 하이라이트) 처리해 "쏟아붓는" 인상을 주는 것** — 신규 이펙트 종류 추가보다 **기존 연사 이펙트의 타이밍감·명도 대비**를 다듬는 쪽이 이 레퍼런스가 주는 가장 큰 시사점이다.

## 6. 한계 및 후속 제안

- §1(일반 아트 디렉션 서술)은 영상 제목/메타데이터 + HighFleet 공개 자료 기반이고, §2(실측 팔레트·구도)는 **대표님이 첨부한 실제 전투 스크린샷 1장을 직접 분석**한 결과다.
- 스크린샷 1장 기준이므로, 다른 장면(예: 원거리 포격, 완전 야간, 격침 직전 등)의 색감 편차가 있을 수 있다. 추가 스크린샷을 첨부해주시면 §2 팔레트를 더 정교화할 수 있다.
- 착수 여부·우선순위는 대표님 지시 후 별도 READY 작업으로 분리 — 이 문서는 참고·제안 단계이며 CSV/코드 변경은 없다.
