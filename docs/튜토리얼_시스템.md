## 0. 한 줄

최초 아르카디아 착륙부터 허브 실습이 끝날 때까지, **튜토리얼이 게임의 유일한 전면**이다.  
모든 메뉴를 잠그고 오퍼레이터가 가리킨 버튼만 누르게 하며, **다른 요소는 등장·입력·알림을 하지 않는다.**  
채굴 → 무역 → 조선소 → 대화 → 바 → 출발 순으로 **빠짐없이** 경험한 뒤에만 세계가 열린다.

### 0-A. 김클로드 전수조사 흡수 (v0.3)

김클로드 `PARTIAL` · 김팀장 코드 재대조. 골격(강제 순차·화이트리스트·Table-First·착수 전 승인)은 유지. 아래만 설계에 넣었다.

| ID | 판정 | 반영 |
|----|------|------|
| **P0-1** 발화 시점 | **AGREE** | `initTutorialStory`는 인트로 끝이 아니라 **캐릭터 생성 직후**. 인트로 완료 호출은 가드 no-op. §2-1·§6-2·§14 정정 |
| **P0-1b** 이어하기 | **김팀장 추가** | `app/index.tsx`도 `getActiveMission()` 없으면 호출. D2 전 persist를 비우면 이어하기가 미션을 다시 켬. 1안은 **세 발화점** |
| **P0-2** 스파이 자동 대화 | **AGREE** | §1-A-3 침묵. `spyIntelAutoOpenDialog` 기본 true |
| **P1** 배틀레디 | **AGREE** | §1-A-3. 웨이브와 별개. `usePlanetHubBattleReady` |
| **P2** 뱃지 3소스 | **AGREE** | 무역·바·명단. 표시 숨김 |
| QuestHUD 빈 숨김 | **참고 채택** | 미션을 D2까지 안 켜면 HUD는 추가 게이트 없이 숨음 |

게임 코드는 이 턴에서 쓰지 않음.

## 1. 기획 의도

일반 모바일 게임의 **강제 가이드**다. 선택·스킵·옆길 없음.

| 원칙 | 내용 |
|------|------|
| **강제 · 최우선** | `hubTutorial.running`이면 튜토리얼이 입력·오버레이·STAGE 전환의 **1순위**. 다른 시스템은 대기하거나 발사하지 않음 |
| **무간섭** | 플레이어가 오퍼레이터·타깃 버튼 외에 **아무것에도 방해받지 않음** |
| **전부 진행** | 설계에 올린 스텝은 모두 통과해야 완료. 권장/선택 스텝 없음 |
| 전부 잠금에서 시작 | 허용 목록 밖 버튼은 `disabled` + 입력 무시 |
| 한 번에 하나 | 오퍼레이터 대사 → 대상 버튼 하이라이트 → 클릭 → 실제 기능 1회 → 다음 스텝 |
| 경험 후 해금 | 설명만 듣고 넘어가지 않음 |
| UI·버튼이 정본 | 1차는 허브에 **이미 있는** 타일·시설·탑바만 |
| 오퍼레이터 = 유일한 입 | 화자 `npc_cpt_operator_stella`. 아크코어 채팅·다른 NPC 자동 대사는 침묵 |

## 1-A. 강제 · 무간섭 계약 (최우선 · 다른 절보다 앞선다)

`status === running`인 동안 아래를 **예외 없이** 적용한다.  
구현 시 `isHubTutorialActive()`가 true이면 해당 입구는 **early return**.

### 1-A-1. 플레이어가 할 수 있는 것 (화이트리스트만)

| 허용 | 조건 |
|------|------|
| 오퍼레이터 대사 `[ 다음 ]` | 현재 스텝 대사창이 떠 있을 때만 |
| 지금 스텝의 타깃 controlId **1개** | 대사 종료 후. 게이지·시설 내부의 그 스텝 통과에 필요한 조작만 |
| 시설 스텝의 `[ 뒤로 ]` | 그 시설에 **들어온 뒤** 복귀가 통과 조건일 때만 |

이 밖은 전부 거부. **스킵 버튼 없음. 나중에 하기 없음.**

### 1-A-2. 잠그는 입력 (하드라이드)

| 대상 | 강제 동작 |
|------|-----------|
| 허브 타일·시설·출발 | 타깃 외 `canPressHubControl === false` |
| 탑바 전원·설정·랭킹·재화·BM | **잠금**. 튜토리얼을 설정으로 빠져나가지 않음 |
| 파일럿 헤더 펼침 | 잠금 |
| 퀘스트 HUD 탭 | **숨김**. `mission_001`도 D2 전까지 시작하지 않음 |
| 궤도 NPC 마커·명단 | `dialog` 스텝 외 잠금 |
| 아크코어 `[대화]`/채널 | `presentArcCoreBackchannel` 거부 |
| 스크롤로 다른 메뉴 찾기 | 딤이 타깃 외 히트를 막음. 스크롤은 타깃이 보이도록만 |

OS 홈·앱 전환은 막지 않는다. 재개 시 **같은 스텝부터** 강제 재개(§6-3).

### 1-A-3. 끼어들면 안 되는 시스템 (침묵 목록)

튜토리얼보다 **우선할 수 있는 것은 없다.** 아래는 `running` 동안 발사 금지. 이미 떠 있으면 dismiss.

| 축 | 입구 | 침묵 |
|----|------|------|
| 선제 대화 | `armArcCoreInboundTalkHubSlot` / inbound Alert | 무장 해제. 타이머 정지 |
| 아크코어 채팅 | `presentArcCoreBackchannel` · boot-chat | 거부 |
| 전투 후 채팅 | wave `combat_end` | 튜토리얼 중 웨이브 자체가 없음 |
| 웨이브 디펜스 | `useWaveDefenseController` 자동 시작 | **금지**. 아르카디아 `tutorial_escape`도 실습 중 시작 안 함 |
| 반란·WDI 오퍼레이터 | `notifyPlanetRebellionOperatorAlert` | 큐에 넣지 않음. 완료 후 재생 가능 |
| 착륙 대사 경합 | `early_route_arcadia_hub` 엘렌 등 `planet_landed` | 스텔라 스텝 씬만. 다른 landed 씬 스킵 |
| **스파이 정보원 자동 대화** | `planet.tsx` `presentPlanetHubSpyIntelDialog` · `spyIntelAutoOpenDialog` 기본 **true** | **금지**. 가드가 `isIngameDialogActive()`뿐이라 스텔라를 밀어낼 수 있음. `isHubTutorialActive()` 필수 (김클로드 P0-2) |
| **허브 배틀레디** | `usePlanetHubBattleReady` · `evaluateHubMainStageCombatEntered` | **금지**. 웨이브와 **별개** 경로. 적대 함대 진입 시 점멸 배너·카운트다운 후 전투 오비트. running 중 `enemyFleetEntered`를 막거나 배너·오비트 진입을 막음 (김클로드 P1) |
| 미션 클리어 대화 | `tryPresentPendingMissionClearDialog` | D2 전 대기 |
| QuestHUD / 첫 비행 | `initTutorialStory` | D2 전 **세 발화점 모두** 호출 금지 (§6-2) |
| Alert/레벨업/보상/상점 | `showArcAlert` · levelUp · BM · waveResult | 튜토리얼 전용 안내 외 금지 |
| 메뉴 뱃지 (3곳) | `menuNotificationStore.setBadge('trade')` ← `mining/service.ts` · `setBadge('bar')` ← `barBoardStore` · 명단 `hubDialogBadgeRev` / `planetHubTalkRosterHasBadge` | **표시 숨김**. 쓰기 자체는 persist를 건드리지 않게 게이트하거나, 타일 `showBadge`만 끈다 (김클로드 P2) |
| 일일 배치 UI | 배치 자체는 차원항로 정본 유지 | **팝업·채널로 허브를 가리지 않음** |
| 인바운드 드론 연출 | 허브 회피 UI | 튜토리얼 중 입력·알림 없음 (연출 최소) |

우선순위:

```text
OS > 튜토리얼 오퍼레이터 대사 = 튜토리얼 타깃 입력
     > (그 외 게임 UI · 오버레이 · 미션 · 전투 · 채팅) = 0
```

새 기능·알림을 넣을 때 `isHubTutorialActive()` 게이트가 없으면 **설계 위반**.

### 1-A-4. 스텝은 생략하지 않음

A0~D2에 올린 스텝은 **필수**다. C(대화·바)도 권장이 아니라 강제.  
통과 조건을 약화해 건너뛰지 않는다.

| 금지 | 대신 |
|------|------|
| 스킵 / `status: skipped` | 상태 머신에 skip 없음 |
| 「나중에 판매」로 A5 통과 | 채굴 1사이클을 기다렸거나, 재고가 생긴 뒤에만 판매 통과 |
| 바·대화 생략 | C1·C2 필수. 바에서 **의뢰 수락 버튼은 잠금**(옆길로 안 빠짐) |
| 설정에서 튜토리얼 종료 | 설정 잠금 |

판매 스텝이 광물 0으로 멈추면: 경제 시드 변경 없이 **A2 채굴이 1사이클을 끝낼 때까지 A5를 열지 않음**. 강제 지급 없음.

### 1-A-5. 시설 안에서도 강제

무역소·조선소·바에 들어가면 그 스텝의 목표만 한다.

- 다른 탭·구매·의뢰 수락·출발 연동 잠금
- 목표 달성(판매 1 / 기함 확인 / 게시판 열람) 전에는 허브로 나가도 스텝이 안 끝남. 다시 그 시설만 열림
- 조선소 「기함 확인」= 기함 행이 보이거나 상세를 연 것. 구매 아님

### 1-A-6. 스킵을 나중에 열 때

기본은 **스킵 없음**.  
스킵을 넣으려면 대표님 별도 승인. 넣더라도 설정이 아니라 **마지막 대사에만** 두고, 기본 경로는 강제 순차 유지.

## 5. 따라가게 만드는 장치 (UI)

상용 튜토리얼과 동일한 3층.

```text
1) 오퍼레이터 대사 (기존 IngameDialogHost)
2) 닫힌 뒤: 딤 + 타깃 타일만 통과 (허브 포그라운드 1 View)
3) 타깃 외 press = no-op (disabled)
```

| 규칙 | 내용 |
|------|------|
| 대사 중 | 허브 버튼 전부 잠금. `[ 다음 ]`만 |
| 대사 후 | 타깃 1개만 G1. 스포트라이트는 `measureInWindow` **스텝 진입 1회** |
| 손가락 에셋 | 1차는 하이라이트 테두리만. 전용 손가락 PNG는 2차 |
| 오클릭 | Alert 남발 금지. disabled면 무시. 타깃이 아닌 해금분을 눌러도 무시 |
| 시설 안 | 해당 스텝이 요구하는 하위 버튼만(예: 판매). 그 외 시설 탭은 잠그거나 「뒤로」만 허용 |
| STAGE | 튜토리얼 중 `departure` 전 `replace` 월드맵 금지 |
| 오버레이 | 신규 RN Modal 금지. 딤은 허브 자식 또는 `ArcOverlayHost` blocking 1개 |

레이아웃 상수(`PLANET_MAIN_*`)는 스포트라이트를 이유로 바꾸지 않는다.

## 6. 상태 · 플래그 · 기존 미션과의 관계

### 6-1. 권장 상태 (신규, 계정 귀속)

가칭 `hubTutorial` (persist 키는 구현 시 확정. purge 연동 필수).

```text
status: locked | running | completed
// skipped 없음 — 강제 완주만
stepId: A0 | A1 | … | D2
unlockedControlIds: string[]   // 누적 해금
startedAtMs / completedAtMs
```

- **계정 진행**. `purgeLocalAccountData`에서 리셋.
- 월드/경제 축 아님.
- `planetHubScanUnlock` 세션 Map과 **별개**. 스캔 규칙(출발 후 재스캔)은 튜토리얼 **완료 후** 지금과 동일.

`player.flags`에 이미 있는 값:

| 플래그 | 지금 | 설계 후 |
|--------|------|---------|
| `introSeen` | 인트로 종료 | 유지 |
| `firstMissionStarted` | 인트로에서 true | **허브 D2 이전에는 여행 미션을 켜지 않음** |
| `tutorialComplete` | `mission_*` 종단 | **이름 유지** = 은하 튜토리얼 스토리 완료. 허브 실습은 `hubTutorial.completed` |
| `seenStorySceneIds` | `ingame_dialog_01` 등 | 스텝 씬 id 추가 |
| `pendingArcadiaDialog01` | hydrate만, 사실상 미사용 | 신규 로직에 기대지 않음 |

### 6-2. `initTutorialStory` 충돌 (핵심 · 김클로드 P0-1 + 김팀장 보강)

v0.2는 「인트로 완료 시점에 호출된다」고 가정했다. **코드 재대조 결과 그 가정은 틀렸다.**

| # | 실제 호출 | 시점 | 비고 |
|---|-----------|------|------|
| 1 | `src/game/onboardingPilotRegistration.ts` | **캐릭터 생성 직후** · 인트로 시네마틱 **전** | **진짜 1차 발화** |
| 2 | `src/game/ingameDialog/ingameDialogCompletion.ts` (`runIntroSeenAndStartFirstMissionPolicy` · `start_mission`) | 인트로/`ingame_dialog` 완료 | `activeMissionId` 가드라 **사실상 no-op** |
| 3 | `app/index.tsx` 이어하기 | `introSeen`이고 `getActiveMission()`이 없을 때 | 김클로드 누락 · **김팀장 추가**. D2 전 persist를 비워 두면 이어하기가 미션을 다시 켬 |

`firstMissionStarted`는 세터만 있고 다른 모듈이 읽지 않는다. 발화 시점을 D2로 늦춰도 이 플래그 부작용은 없다.

**1안 (권장 · 세 곳 모두)**

1. 캐릭터 생성 · 인트로 완료 · 타이틀 이어하기에서 `initTutorialStory()`를 **호출하지 않음** (`hubTutorial.completed`가 아니면).
2. 허브 `planet_landed`(아르카디아) → 허브 튜토리얼 A0. 메뉴 전면 잠금. QuestHUD는 활성 미션 0이면 이미 `return null` (`QuestHUD.tsx`) — D2 전 미션을 안 켜면 **추가 HUD 게이트 없이** 숨겨진다.
3. D2에서만 `initTutorialStory()` + `departure` 해금 + (원하면) `firstMissionStarted = true`.
4. `player.flags.tutorialComplete` 의미는 그대로(미션 체인 끝).

인트로 `completionPolicy` 문자열 자체 변경은 **기존값**이다. 구현 전 재확인.  
호출을 빼는 것은 정책 동작 수정이지 CSV 문구 덮어쓰기가 아니다.

### 6-3. 재접속 · 중도 이탈

| 상황 | 동작 |
|------|------|
| A1 이후 앱 종료 | `stepId` persist. 재착륙 시 해당 스텝 대사부터 |
| 시설에서 백 | 스텝이 시설 진입을 요구했으면 복귀 시 통과 판정 |
| 계정 초기화 | 허브 튜토리얼·스캔 세션·미션 전부 리셋 |
| 이미 `hubTutorial.completed` | 게이트 없음. 현재 허브와 동일 |
| 기존 유저(플래그 없음) | `introSeen && firstMissionStarted` 이면 **소급 완료**로 간주. 강제 리플레이 없음 |

대사 본문은 `story_scene_pages.csv`. A0=`ingame_dialog_01`(이미 교체). A1–D2는 신규 행.  
정본 문장: `docs/EARLY_STORY_AND_QUEST_SPINE.md` §4-6.

빌드: `build:content-tables` 확장. Fable 축(CSV) + 김팀장(허브 게이트 UI).

## 8. 런타임 계약 (구현 전 스케치)

단일 입구. 화면마다 if 산재 금지.

```text
isHubTutorialActive()                 // running이면 true — 전 시스템 1순위 게이트
isHubTutorialSuppressing(kind)        // inbound | chat | wave | battleReady | spyIntel | alert | missionHud | landedOther | badge
getHubTutorialAllowedControlIds(): ReadonlySet<string>
canPressHubControl(controlId): boolean
noteHubTutorialEvent(event, param?)   // 스캔 완료·채굴 시작·시설 진입 · 판매 1회
```

- `PlanetHubActionTile` / 시설 `onPress` / 탑바 / 출발이 `canPressHubControl`을 공유.
- `noteHubTutorialEvent`는 기존 콜백에 한 줄: `handlePlanetScanComplete`, 채굴 start, `onFacilityNavigate`.
- 오퍼레이터 present는 `presentIngameDialogScene`만. 입구 추가 금지.
- 부트·타이틀 버튼에 튜토리얼 대기 금지.
- §1-A 침묵 목록의 모든 입구가 `isHubTutorialActive()`에서 막힘. 새 팝업은 이 게이트 없이 추가 금지.

## 9. 메모리 · STAGE

- 스텝 전환 때만 setState. 하이라이트 rAF/매 프레임 `measure` 금지.
- 스포트라이트 rect는 스텝 진입 1회.
- persist는 스텝 통과 시 coalesce (채굴 틱마다 금지).
- 허브 `route_blur` 시 딤 해제. 시설 `push`는 행성이 스택에 남으므로 게이트 상태 유지.
- 월드맵/전투 튜토리얼 오버레이 없음 (1차).
- Skia 채굴 궤도는 기존 경로. 튜토리얼이 루프를 추가하지 않음.

## 11. 검증 시나리오 (코드 전 체크리스트)

1. 신규 계정 → 인트로 → 아르카디아 → 메뉴·탑바 전부 잠김 → 스텔라 A0. QuestHUD 없음.
2. 스캔만 눌림 → 게이지 후 채굴만 눌림. 다른 타일·Alert·inbound 없음.
3. 채굴 1사이클 → 무역소만 열림 → **판매 1회 필수**.
4. 조선소 입장·기함 확인·복귀. 구매 잠금.
5. 대화 명단 1회 → 바 열람(수락 잠금).
6. 그 전 출발·월드맵·웨이브·아크코어 채팅 불가.
7. running 중 엘렌 착륙 대사·반란 알림·BM·레벨업·**스파이 자동 대화**·**배틀레디 배너/오비트**가 **한 번도** 안 뜸.
8. D2 후 `mission_001` QuestHUD + 출발 가능. 침묵 목록 해제.
8b. D2 전 타이틀 이어하기를 해도 `initTutorialStory()`가 다시 켜지지 않음. 같은 스텝 강제 재개.
9. 완료 계정 재접속 시 잠금 없음.
10. 계정 초기화 후 1부터 강제 재시작.
11. 기존 유저 소급 완료 — 이미 플레이 중인 계정은 강제 리플레이 없음.
