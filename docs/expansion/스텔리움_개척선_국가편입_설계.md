## 0. 잠금 원칙 — 계정 초기화와 국경 (명기)

**현재 국경·영토는 아크코어가 제어하는 수준에서 움직인다.**  
계정 초기화를 해도 CSV 시드와 아크코어 영토 패스의 결과가 남아, **초반 게임성(노드·접경·튜토리얼 동선)이 유지**된다.

**플레이어가 심각하게 관여한 데이터가 남으면 초기화가 흔들린다.**  
정찰·행성정보·개척 성공으로 넓힌 파란 칸이 다음 회차에 남으면, 초반에 비어 있어야 할 중립 노드가 줄고 접경·이동 압력이 커진다.

| 축 | 초기화 | 이유 |
|----|--------|------|
| CSV 시드 BLUE/RED · 아크코어 영토 전투로 바뀐 hold | **남김** | 세계 축. 제어된 변동. 초반 골격 유지 |
| 월드 금고 · 일일 경제 · 성계 개방(아크코어) | **남김** | 기존 헌법. 계정과 무관 |
| 플레이어 독립국·거점·증서 | **지움/중립화** | 기존 `planetHoldReleasePolicy` |
| **개척 전 과정** (정보 열람 트리거 · 임시전초기지 · 항해 · 실패 대기 · **사령부 성공 hold**) | **전부 지움** | 플레이어 정찰이 만든 국경. 회차 초반을 지킴 |

구현 시 성공 hold에 **개척 유래 표시**가 필수다. 없으면 purge가 시드 블루와 개척 블루를 구분하지 못한다.

## 1. 한 줄

플레이어가 **개방 성계에 착륙해 행성정보를 연 뒤에만** 스텔리움 개척선이 뜨고, **1~3일(거리)** 뒤 행성 기본값 확률로 사령부를 시도한다. 지금은 **블루만**. 성공해도 **다음 캐릭터 초기화 때 그 국경은 되돌린다.**

## 2. 재검토 결론

| # | 판정 | 내용 |
|---|------|------|
| 의도 | **유지** | 정찰 → 전초기지 → 개척선(수송 마크) → D일 → 확률 사령부 → 국경 |
| 시계 | **유지** | 일 1회 배치 + 벽시계 catch-up. 틱 금지 |
| 자격 | **유지·강화** | 개방 ∧ 착륙+정보 ∧ NEUTRAL/프론티어. RED·분쟁·독립국·이미 BLUE 제외 |
| 확률 | **유지** | 1차 50~70 → 2차 60~80 → 이후 상향, 행성 R/P/D/T/E 밴드 |
| 표시 | **유지** | 아크 수송과 동일 마크. 교역 정산과 분리 |
| purge | **개정 잠금** | 개척 유래는 성공 포함 삭제. 아크코어 영토는 유지 |
| synth phase | **분리 유지** | 매일 +1 시설 단계 ≠ 국가 편입 |
| 서브코어 | **금지** | 배치 패스 + 기존 궤도 슬롯 |
| 입≠몸 | **유지** | 대화가 출항·성공을 write하지 않음 |
| 타 국가 | **확장 가능 · 조건부** | §6. 지금은 블루만 |

## 3. 상태기계 (블루 1차)

```text
미대상
  │  개방 AND 착륙+행성정보 AND §4 자격
  ▼
임시전초기지 + 개척선 출항
  ▼
항로 이동  D일 (최근 BLUE hold까지 홉 1/2/3+ → 1/2/3일)
  ▼
사령부 시도 N   (dayKey+planetId+attempt 고정 시드)
  ├─ 성공 → BLUE hold + 개척유래 태그 + Voronoi 국경
  └─ 실패 → 같은 D일 후 N+1
```

동시 항해 상한 3. 초과는 대기열(가까운 홉 우선).

## 4. 자격 · 확률 · 국경

**출항**: `unlockedSystemIds` ∧ `isPlanetInfoRevealed`(착륙 후 정보) ∧ hold가 NEUTRAL/프론티어.  
제외: RED 시드, `contestedZone`, 플레이어 독립국, 이미 BLUE.

**확률 밴드** (`stellium_colonize_policy.csv` 예정, 코드 하드코딩 금지)

| 시도 | 밴드 | 행성 기본값 |
|------|------|-------------|
| 1 | 50~70% | D·가혹 E → 하단. P·T → 상단 |
| 2 | 60~80% | 동일 방향 |
| 3+ | 70~90%, 캡 95% | 동일 |

**성공 write**: `occupierClanId = balance_seed_faction_blue` + `origin = player_colonize`(가칭).  
지도는 기존 Voronoi. 새 국경 엔진 없음. 체감은 점유 플레이트 + 보드 1줄. 팝업 남발 금지.

## 6. 크림슨 · 남북 확장 재검토

4대 국호는 이미 있다. **같은 상태기계(D일·확률·마크·일 배치)는 복제 가능**하다.  
막히는 곳은 **점유 색**과 **누가 정찰하는가**다.

| 국가 | F | 전쟁 hold | 1차(지금) | 이후 | purge |
|------|---|-----------|-----------|------|-------|
| 스텔리움 연합 | F1 | BLUE | 플레이어 정찰 필수 | — | 개척 유래 **전부 삭제** |
| 크림슨 레기온 | F3 | RED | **안 함** | 자동 개척선(플레이어 역할 대체) | 자동분은 **아크코어 제어 → 남김** (영토 패스와 동일 수준) |
| 머큐리움 연합 | F2 | **hold 삽입 금지** (2026-08-15 잠금) | 안 함 | 같은 시계·마크는 가능. **국경 색은 못 씀** | 오버레이만이면 월드 축. hold 색 변경은 잠금 해제 전 불가 |
| 아우렐리움 길드 | F4 | **hold 삽입 금지** | 안 함 | F2와 동일 | F2와 동일 |

### 6-1. 크림슨 — 확장 가능 (거울)

- 테이블에 `factionId`만 있으면 패스를 나눌 수 있다.
- 출항은 **플레이어 정보 없이** 자기 RED 국경 1홉 중립만. 일 배치 성공 상한 1.
- 성공 = RED hold. Voronoi는 기존 전쟁축.
- 플레이어가 열지 않았으므로 **남기는 것**이 §0과 맞다. 속도·인접 캡을 지키면 초반 골격은 영토 패스와 같은 “제어된 변동”이다.
- **지금 구현하지 않음.**

### 6-2. 남북 — 부분 가능 (국경 색 불가)

- 교역 F·국호·항로는 준비됨. 남·북 **선단 운영자**는 아직 아크 1개.
- 개척 개념을 얹어도 **hold에 F2/F4를 쓰면 안 된다.** 파란/빨간 칸으로 위장 편입도 금지.
- 가능한 1단계: 수송 마크 + 임시 주둔 라벨(flavor). 전쟁 국경은 불변.
- 진짜 4색 국경은 **hold 잠금 해제 + Voronoi 사이트 확장**이 선행이다. 그때 다시 게이트.

### 6-3. 확장 시 같은 실수

| 하면 안 됨 | 이유 |
|------------|------|
| 스텔리움 성공 국경을 purge에 남김 | 회차 초반 노드 붕괴 (§0) |
| 크림슨 자동 성공을 플레이어 관여분처럼 지움 | 아크코어 세계를 매 회차 시드로 되돌림 |
| 남북 성공을 BLUE/RED hold로 기록 | 4대 국가가 전쟁 2색에 흡수됨 |
| 개척과 교역 선단 화물/금고 공유 | 확장 마스터 G8 위반 |
| 13번째 서브코어 | 헌법 |
