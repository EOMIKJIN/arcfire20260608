## 2. 배드케이스 — 무엇이 실패였나 (v0.1 고정 · 삭제 금지)

### 2-1. 실패의 한 줄

대표님 의도는 **「캠페인 끝난 뒤의 반복 시스템」** 이었다.  
구현은 **부트 직후·아르카디아 접선·초반 전선부터** 보호창·편입·징수·플레이봇 annex가 돌았다.  
지시가 잘못 전달·해석된 뒤, **의미를 재확인하지 않고 설계·개발까지 진행**한 사례다.

### 2-2. 원래 제안(1안) — 당시 문구

| 1안 항목 | 당시 의도 | 실제 구현 |
|----------|-----------|-----------|
| 인접 편입 | 중립을 스텔리움으로 닫아 보드가 살아나게 | 코어 전 행성·`player_home` 접선으로 **초반부터** 열림 |
| AI 반격 번짐 | 이긴 뒤 세계가 되살아나게 | **미구현.** 반대로 보호창이 NPC 점유를 30분 막음 |
| 이긴 날이 지도에 남게 | 잔상 | `neutralizedAt`만 데이터. 지도 표기 없음 |
| 캡 이후 싱크(금고) | 종반 보상 | 중립화마다 **2000cr 하드코딩** |
| 캡 이후 싱크(함대) | 성과가 함대에 남게 | 군사령부 패스 **+6%** — 로테이션 수학 변조 |

게이트 판정은 **부모 missionId 클리어**이지 objective 개수 합이 아니다.

### 5-4. 경제 · 소유 · 점유 (구매 가능 여부)

| 항목 | 정본 값 | 시뮬 |
|------|---------|------|
| 소유권 증서 | `item_defs` `ownership_{planetId}` **전부 12,000cr** | 코어 21기 = **252,000cr** |
| 편입비 | CSV 8,000 · **블루 금고** | 금고 0이면 편입 불가 (봇 HOLD 원인) |
| 독립국 | hold `kind=player_independent` · 출처 `player_ownership_purchase` | 무역소 증서 구매 → 로컬 영토 |
| 점유 시드 | 초반 7기 BLUE · 중후반 RED(오메가·시리우스·크림슨·어비스·코어 등) | 로테이션이 RED/N을 **재공급** |
| 개척 | `stellium-colonize` 블루만 | 봇 `colonizeOk=0` |

**독립국 1기 = 12,000cr.**  
플레이봇 D5000 현금 ≈ 245k → **1기는 충분히 구매 가능. 21기 전량은 현금 전액을 비워야 하고, 봇은 한 번도 안 샀다.**  
「내 독립국가까지 구매」게이트는 **전 행성 매입이 아니라 ≥1** 이다.

**전 성계 블루 21/21** 은 20분 `draco_front`가 승자 행성을 다시 분쟁·RED로 돌리는 한 **안정 평형이 아니다.**  
봇 장기 평형은 **B10–11 / R7–8 / N3** 부근에 고정됐다.  
대표님 조건 「밸런스상 가능한 지표가 나왔다면」→ **지표는 나왔고, 불가다.** 하드게이트 금지.  
소프트 관측만 둔다: `blueCount ≥ redCount` 또는 플레이어 독립국 거점이 도색된 상태.

| 개척으로 메움 | 봇 0 · 크림슨 거울 미실기 | 게이트로 쓰지 않음 |
| 장기 평형 | **B≈10–11 고정** | D5000 · 학습 히스토리 동일 밴드 |

**결론:** 전 성계 블루는 v0.2 입장 조건이 아니다.
