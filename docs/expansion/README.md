## 신규 확장 등록 절차

1. 마스터 설계안 **§4 공통 게이트** 표에 PASS/조건부/불가 기입  
2. 본 대장에 `id` · 문서 경로 · 상태 한 줄 추가  
3. 구현은 대표님 지시 후. READY가 있으면 `tools/kim-team-lead/reports/`에 두고 **여기 링크**  
4. 구현 완료 시 상태를 `설계` → `구현`으로만 바꾸고, 산재 문서를 늘리지 않는다
