## 0. 문서 목적

행성 허브 **수색(salvage)** 으로 광물·판테온 유물을 얻는 경로를 전수 조사하고,

1. 현재 구현·CSV·확률 상태를 고정 기록하고  
2. 대표님 목표(슬롯형 희귀감 · 고난이도 행성 = 고가치 · 유물 특수스킬 기반)와의 **GAP**을 명시하며  
3. **구현은 본 문서 + 후속 재분석 승인 후에만** 착수한다.

## 5. 확률 수학 (현행)

정본: `src/game/planetSalvageSearch.ts`

```text
relicRoll = hash32("relic:{planetId}:{wreckId}:{attemptIndex}") % 100
if relicRoll < RELIC_DROP_PCT(=5):
  → 미해금 유물 중 seed % N (균등)  · CSV dropWeight 무시
else:
  → 광물 풀 seed % M (균등)
```

| 결과 | 확률 | 비고 |
|------|------|------|
| 판테온 유물 | **고정 5%** | 좌 간 균등 · 전부론 해시 |
| 광물 | ~95% | 5종 균등 |
| 티어/가중 룰렛/피티 | 없음 | — |
| `systemEnemyLevel` 보정 | 없음 | — |

동일 `(planetId, wreckId, attemptIndex)` → **재현 가능** (true RNG 아님).

`planets.csv` `systemEnemyLevel` 밴드 (2026-08-12 스냅샷):

| 밴드 | 대략 수 | 예 | 수색 기대값 |
|------|---------|-----|-------------|

**판정: 「행성 레벨에 맞게 유물 배치」— FAIL**

## 7. 특수 스킬·능력 기반

| 항목 | 판정 | 근거 |
|------|------|------|
| 도감 unlock · purge · 백업 | PASS | codex store |
| 비문 lore 열람 | PASS(부분) | 무역소 유물 탭 |
| `revealLevel` 단계 공개 | GAP | 문자열만 |
| 스킬 트리 / 전투 패시브 연동 | GAP | `skillDbStore`와 relic 키워드 미연결 |
| attrs ability / skillId | GAP | 필드·파이프라인 없음 |

**결론**: 특수스킬 부여 **기반 작업은 가능**  
(예: `item_defs.attrs` 또는 `relic_skill_bindings.csv` → 해금 시 `skillDbStore.syncOwnedSkills`).  
현재는 **자리만 있고 구현 없음**.

## 8. PASS / GAP 총표

| 기준 | 판정 |
|------|------|
| MVP 수색→광물/유물→도감 루프 | **PASS** |

| 틱/폴링 드롭 없음 | **PASS** |

| CSV `dropWeight` / `allowedPlanetPool` 실사용 | **GAP** |
| 레벨별 유물 배치 | **FAIL** (배치 로직 없음) |
| 유물 특수 스킬 | **GAP** |
| WO salvage 버튼 = 허브 수색 | **GAP** (placeholder) |

## 9. 구현 보류 · 후속 방향 (승인 전 초안)

> **본 절은 설계 후보일 뿐. 수치·CSV·코드 변경은 대표님 승인 + 재분석 후에만.**

**1안 (권장 골격)**

1. Table-First salvage 확률표 (`tables/balance` 또는 content)  
   - 밴드: `systemEnemyLevel` 1–5 / 6–15 / 16–25 / 26+  
   - 티어: 일반 광물 · 고급 광물 · 유물(jackpot)  
2. 아르카디아 근처 유물률 ↓ · 고난이도 ↑ + `dropWeight` 실사용  
3. `allowedPlanetPool`로 후반·고가치 좌를 외곽/고레벨에 배치  
4. 특수스킬:  
   - Phase 1 — attrs/`relic_skill_id` + 해금 시 skill store 등록  
   - Phase 2 — 전투/패시브 수치 연동  

**작업 분담(착수 시)**

| 축 | 담당 |
|----|------|
| CSV·시드·풀·가중 | Fable |
| `planetSalvageSearch` · 허브 연동 · 메모리 게이트 | 김팀장 |
